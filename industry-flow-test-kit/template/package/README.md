# Пакет «mebli» (тестовий каркас)

Тестовий пакет галузі «Виробництво меблів» (КВЕД-2010 розділ 31) для перевірки скілів пакета `industry-flow` на етапі 1 (без Odoo).
Це не продукт: файли тут — каркас і результати тестових кроків.

- Код пакета: `mebli`. Галузь: КВЕД-2010 розділ 31 «Виробництво меблів». Мова: українська.
- Політика даних: `package/DATA_POLICY.md` (заповнена для тесту).
- Параметри флоу: `flow/params.md`. Стан: `flow/state.md` (заглушка). Рішення людини: `flow/decisions.md`.
- Робочі матеріали галузі: `docs/industries/mebli/`. Результат скоринга (A-01): `docs/industries/scoring.md`.
- Наряди тесту: `tests/naryad/`; звіти: `tests/reports/`; зауваження до скілів: `observations/`.
