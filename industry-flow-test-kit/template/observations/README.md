# observations/ — зауваження до скілів

Сюди людина (або сесія за її вказівкою) записує знахідки тесту. Спосіб запису: викликати скіл `boost:skill-feedback` («запиши замечання до скіла X: …») — він створює файл у `observations/` у своєму форматі; сам скіл не править.
Одне зауваження — один файл. Назвати: скіл, крок, що очікували, що вийшло, де в `SKILL.md` розбіжність. Якщо `boost:skill-feedback` недоступний — файл `observations/<YYYY-MM-DD>-<скіл>-<крок>.md` з тими самими полями.
Окремо позначати: (а) скіл не знайшов вхід, який мав за контрактом; (б) шлях/формат у скілі не збігається зі шляхом/форматом сусіднього скіла; (в) тестова розкладка (CLAUDE.md) не покрила посилання скіла; (г) відкрите питання до власника пакета.
