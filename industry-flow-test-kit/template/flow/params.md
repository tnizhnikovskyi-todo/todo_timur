# Параметри флоу (тест, затверджено для тесту)

## A-01: критерій ранжування галузей
Текст критерію для `--param` check_scoring.py — окремий файл `flow/params/A-01-criterion.md` (лише формула й умови, дослівно як у `flow/decisions.md` №1).
Статус: тест, затверджено для тесту · Затвердив: Власник продукту (тест) · Дата: 2026-11-10 · Запис журналу: `flow/decisions.md`, рядок №1.

Формула (змінні лише з `industry-flow-marketplace/plugins/flow-research/skills/industry-scoring/references/scoring-formula.md` §5):
`бал = 0.4·norm(companies) + 0.4·norm(revenue) + 0.2·norm(growth)`, де `norm(x)` — min–max нормалізація за розділами в межах рейтингу.
Рівень групування: розділ КВЕД-2010 (`LEFT(kved_2010,2)`).
Виключені розділи (літерами): O, T, U (розгортання в двознакові — за `references/kved-2010-sections.md`).
«Рішення на ринку» — лише колонка, на бал не впливає. Рівні бали — за виручкою спадно з позначкою «рівний бал».
Дата знімка реєстру: береться з опису MCP `odb-catalog` або з входу наряду «Реєстр компаній (знімок з датою)».
Відкрите питання до людини: ваги 0.4/0.4/0.2 — тестові, не рішення Власника продукту для бойового режиму.
