## 9. Правила
**RB-01 Маршрутизація (усі 9 видів).** `command(op)` при `_td_route='energy'`: `prepare` — (1) `flow.normalize(kind, params)` (R-08, повідомлення td_chp); (2) preflight td_chp (`interlocks.build_checks(unit, kind, snapshot, routed=True)`, `verdict`) → `pre`; (3) `res=td.energy.control.prepare(<код виду td_energy>, params)` від імені користувача (класи, TTL, стоп-крани, дедуплікація — td_energy_control R-39, R-40); (4) жорстка невдача `pre` → `action._me()._td_close('blocked', reason)`, відповідь `blocked=true`, `token=None`; (5) інакше DTO за RB-02. `confirm` — перевірка токена, повторний preflight лише для `prepared` (невдача → `_td_close('blocked')`), далі `td.energy.control.confirm(token)`; `confirm_second` — preflight для `awaiting_second`, далі `td.energy.control.confirm_second(action_id)`; `cancel` → `cancel(token)`; `get` → `get_action(action_id)`. Відповідність видів: `start→chp_start`, `stop→chp_stop`, `estop→chp_estop`, `reset→chp_reset`, `set_mode→chp_set_mode`, `set_setpoint→chp_set_setpoint`, `set_cos→chp_set_cos`, `set_heat_dir→chp_set_heat_dir`, `set_bypass→chp_set_bypass`. `ref="energy:<action_id>"`; посилання `chp:` (команди, створені до встановлення моста) обробляє td_chp.
**RB-02 Мапінг DTO.** `prepare`: `ref`, `action_id`, `token`, `ttl_s`, `verify_timeout_s`, `cls`, `title`, `text`, `sub`, `needs_second`, `confirm_label`, `disabled_reason` — з `res`; `kind` — вид td_chp; для 7 видів моста `title/text/sub` — з `flow.render` (українські назви режимів), для `start`/`stop` — з `res`; `checks` = preflight td_chp + `res.checks`; `blocked = res.blocked or pre.blocked`; `blocked_reason` — перша невдала. `confirm/confirm_second/get/cancel` — поля API-18…22 td_energy_control + `ref`; ключі `state` ті самі. `UserError`/`AccessError` td_energy_control проходять як є.
**RB-03 Журнал.** `_td_command_rows(unit,limit,before)`: `td.energy.action` вузла `unit.energy_node_id` з `kind_code` одним із 9 видів або `kind_code ilike 'auto\\_%chp%'`, `state∉{prepared,cancelled}` → `{"type":"command","id","ref":"energy:<id>","ts":finished_at|prepared_at,"level":"warn" для failed/blocked/expired, інакше "info","text":"Команда «{вид}»: {стан}" (+ « · 1/2 {prepared_by}, 2/2 {second_by}»; для `auto_*` — `summary`),"state"}`, `ts desc, id desc`, лише `ts < before`. Подій td_chp про ці команди немає (DB-02).
**RB-04 Очікують 2/2.** `_td_pending_rows(unit)`: `td.energy.action` у `awaiting_second` (`chp_start|chp_stop`; решта видів — клас A, до 2/2 не доходять) → `{"ref","kind","title","prepared_by","can_second":користувач у `td_energy.group_td_energy_manager` (або вищій) і ∉{prepared_by,confirmed_by},"second_expires_at"}`. Пульт опитує `get` кожні 2 с до завершення; крім того, зміна стану дії КГУ дає тік шини `td_chp/update`.
**RB-05 Джерело й вузли (`post_init`, ідемпотентно).** Є `td.source` `MB-U72-CHP` → `unit.source_id` і `source_id` усіх `td.signal` `module='chp'` на нього; `CHP-U72` → `active=False`; вузли — за кодами `CHP`/`QF-CHP`. `uninstall_hook`: сигнали й `unit.source_id` назад на `CHP-U72` (`active=True`), `td_chp.menu_td_chp_root` → `active=True`, зв'язки груп td_energy → td_chp знімаються.
**RB-06 Інваріант.** Після повного `start` (1/2 + 2/2 → `done`), `stop`, `estop`, `set_*`: по одній `td.energy.action` на команду; `td.chp.command`=0; `td.command(origin='chp')`=0; `td.chp.event` без записів про команду; `get_journal` — по 1 рядку команди.
**RB-07 Верифікація видів моста (R-09).** `estop`/`reset` — перше показання `chp/ctl/ack` з `ts ≥ td.command.done_at`: 1 → `done` («Контролер прийняв команду»), 2 → `failed` з текстом R-06 (`chp/ctl/ack_reason`); `set_*` — цільовий сигнал дорівнює значенню (|Δ| ≤ ½ кроку регістра) → `done`; без підтвердження за `td.chp.verify_timeout_s` → `failed` («Контролер не підтвердив команду за N с»). `start`/`stop` верифікує збирач енергетики (API-25).
**Помилки.** Вид деактивовано → `_td_route=None` (потік td_chp). Стоп-кран `td.energy_control.write_enabled=False` → `UserError` на `prepare` усіх 9 видів; `remote_switching_enabled=False` → лише `start` (`chp_start`, `remote_gated`).
