# td_genset_factory3d — специфікація W1 (за посиланням)

Модуль — міст `td_genset` ↔ завод (було `factory3d_genset`; докладно попередні редакції — `docs/modules/td_genset/SPEC.md`, M-01…M-09, V-01…V-09, ADP-01…ADP-10).

**Рішення про розміщення.** Специфікація W1 — **Частина II** файлу `factory3d/build/energy/W1_SPEC.md` (розд. B.0…B.15: M-10, M-11, V-10, V-11, ADP-11, R-14…R-16, AC-74…AC-83, ТБ-11, ТК-G14, ТК-G15, A-19…A-22). Підключено за посиланням, не злито (файл спільний із `td_energy`, ~164 КБ). ID зберігають нумерацію (продовження: M-10+, V-10+, R-14+, AC-74+).
Хостинг меню й екранів `td_genset` у розділі «Генерація й резерв» (`td_energy.menu_td_energy_generation`), приховання плитки `td_genset.menu_root`, факти ДГУ для Пульту/АВР, група «Енергетик» → `td_genset.group_user`. Модуль `td_genset` не змінюється.
