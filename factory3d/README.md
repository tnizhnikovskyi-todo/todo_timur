# factory3d — 3D-модель мебельного цеха и склада

Процедурная сцена: вся геометрия строится скриптом `build_scene.py` из
параметров планировки (зоны, стеллажи, станки, маршрут). Поменяли число
стеллажей или положение станка, перезапустили, и все форматы пересобрались.

## Что на площадке (60 × 30 м, высота 7 м)

| Зона | Что стоит |
|---|---|
| Приёмка, входной контроль | 2 ворот с докшелтерами, фура на разгрузке, стопы на сверке, стол замеров |
| Склад плит | 12 стоп ДСП/МДФ/ХДФ по декорам (высота = число листов) |
| Склад фурнитуры | 3 стеллажа × 5 секций × 4 яруса, 60 ячеек с лотками |
| Склад кромки | 2 стеллажа, рулоны по декорам |
| Буфер у линии | 5 тележек с комплектами |
| Производство | 2 раскроечных центра, кромкооблицовка, присадка ЧПУ, 2 стола сборки, упаковка с обмотчиком |
| Склад готовой продукции | 3 паллетных стеллажа × 5 пролётов × 3 яруса |
| Отгрузка | 2 ворот, собранные паллеты, машина под погрузкой |
| Прочее | офис мастера (2 этажа), ремонтный участок, 2 погрузчика, маршрут изделия дугами |

Состояния (станок в работе, простой, остановлен; ячейка в норме, ниже
минимума, пусто) заданы в скрипте для примера.

## Файлы

| Файл | Для чего |
|---|---|
| `dist/factory.glb` | Веб, Blender, Unity/Unreal. У объектов есть свойства `code`, `kind`, `label`, `desc` (glTF extras) |
| `dist/factory.usdz` | Просмотр на iPhone/iPad/Mac (Quick Look, AR). Ось Y вверх, метры |
| `dist/factory.blend` | Исходная сцена: коллекция на каждый слой |
| `dist/index.html` | Просмотрщик (three.js): виды, слои, клик по объекту, подписи, движение по маршруту |
| `dist/factory_viewer.html` | Тот же просмотрщик одним файлом (модель встроена), открывается двойным кликом без сервера. Нужен интернет для three.js с CDN |
| `viewer/index.html` | Исходник просмотрщика, при сборке копируется в `dist/` |

## Сборка

```bash
python3 -m venv .venv && .venv/bin/pip install bpy   # Blender как Python-модуль (Python 3.13)
.venv/bin/python build_scene.py dist
```

Или в установленном Blender: `blender -b -P build_scene.py -- dist`.

## Просмотрщик локально

GLB грузится по `fetch`, поэтому страницу нужно открывать через веб-сервер,
а не двойным кликом по файлу:

```bash
cd dist && python3 -m http.server 8000
# открыть http://localhost:8000
```

Управление: левая кнопка мыши вращает, правая сдвигает, колесо меняет масштаб.
Клик выбирает объект, двойной клик приближает к нему. Клавиши 1–8 переключают
виды, Esc снимает выбор.

## Как устроена сцена

- Каждый слой — пустышка `LAYER_<key>` в корне `FACTORY`. Просмотрщик
  включает и выключает слои по этим узлам.
- Каждый кликабельный объект несёт `code` (например `FUR-R1-S2-L3`, `CNC-1`,
  `Z-SHEETS`). По этому же коду потом удобно связывать сцену с внешними
  данными (склад, MES, ERP).
- Маячки станков помечены `role=status`, просмотрщик перекрашивает их и мигает
  остановленными.
- Маршрут изделия хранится в extras объекта `FLOW` (`route`, JSON). По нему
  просмотрщик анимирует бегущую точку.
