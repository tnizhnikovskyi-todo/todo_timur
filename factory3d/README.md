# factory3d — 3D-модель меблевого підприємства

Процедурна сцена: уся геометрія будується скриптом `build_scene.py` з
параметрів планування (зони, стелажі, верстати, маршрут). Змінили кількість
стелажів або положення верстата, перезапустили, і всі формати перезібралися.

## Що на майданчику (120 × 72 м, висота 9 м)

| Зона | Що стоїть |
|---|---|
| Приймання, вхідний контроль | 3 ворота з докшелтерами, 2 фури, стоси на звірці, столи замірів, карантин |
| Склад плит | Портальний склад: 42 стоси ДСП/МДФ/ХДФ під порталом із вакуумним захопленням, 3 рольганги подачі на розкрій |
| Склад фурнітури | 6 стелажів × 12 секцій × 4 яруси, 288 комірок із лотками |
| Склад крайки | 3 стелажі, 36 полиць із рулонами |
| Буфер комплектів | 11 візків із фурнітурою під замовлення |
| Розкрій | 2 розкрійні центри та центр пакетного розкрою (штовхач, притискна балка, пневмостоли, світлова завіса, принтер етикеток), нестинг-ЧПК, форматно-розкрійний верстат із кареткою, вертикальна панельна пила |
| Крайкооблицювання | 3 прохідні верстати (секційна станина, гусениця, притискна балка з роликами, кожухи агрегатів, клейова ванна, магазин крайки, повертальний конвеєр), на першому лазерний агрегат і робот повернення деталей; верстат шкантування, прохідний свердлильний |
| Присадка ЧПК | 4 портальні центри (консолі з присосками, Z-каретка, свердлильна голова, магазин інструменту, огорожа, бампери), верстат встановлення завіс, роботизована комірка сортування деталей |
| Збирання, пакування | 6 корпусних вайм із верстаками, автоматична лінія збирання корпусів, станок розкрою гофрокартону, 2 пакувальні столи з палетообмотувачами, лінія термоусадки та обв'язки |
| Дільниця фасадів МДФ | широкострічковий шліфувальний, кабіна нанесення клею, мембранно-вакуумний прес, фарбувальна камера з водяною завісою, автомат фарбування, сушильна камера, лінія УФ-лакування |
| Північна смуга | склад пакувальних матеріалів, склад ЛФМ (бочки, єврокуби), компресорна (2 компресори, ресивер, осушувач), зарядна станція навантажувачів |
| Склад готової продукції | 8 рядів палетних стелажів × 9 прольотів × 4 яруси |
| Відвантаження | 4 ворота, коридори з палетами, 2 машини |
| Інженерія | аспірація (магістраль під покрівлею, рукавний фільтр надворі), витяжка фарбувальних дільниць крізь покрівлю, кільцева пневмомагістраль, спринклери та пожежні шафи; надворі котельня на відходах, силос стружки, брикетувальний прес, два пожежні резервуари з насосною |
| Інше | офіс, ремонтна дільниця, побутові приміщення, 6 навантажувачів, працівники біля верстатів, маршрут виробу дугами |

Стани (верстат у роботі, простій, зупинено; комірка в нормі, нижче мінімуму,
порожня) задані в скрипті для прикладу.

## Файли

| Файл | Для чого |
|---|---|
| `dist/factory.glb` | Веб, Blender, Unity/Unreal. В об'єктів є властивості `code`, `kind`, `label`, `desc` (glTF extras) |
| `dist/factory.usdz` | Перегляд на iPhone/iPad/Mac (Quick Look, AR). Вісь Y угору, метри |
| `dist/factory.blend` | Вихідна сцена: окрема колекція на кожен шар |
| `dist/index.html` | Переглядач (three.js): види, шари, клік по об'єкту, підписи, рух маршрутом |
| `dist/factory_viewer.html` | Той самий переглядач одним файлом (модель вбудована), відкривається подвійним кліком без сервера. Потрібен інтернет для three.js із CDN |
| `viewer/index.html` | Вихідний код переглядача, під час збирання копіюється в `dist/` |

Однакові об'єкти (верстати одного типу, стелажі, палети, комірки) посилаються
на спільний меш. У glTF він зберігається один раз, тому GLB займає близько
9 МБ на ~790 тис. трикутників (35 верстатів, 857 об'єктів).

## Збирання

```bash
python3 -m venv .venv && .venv/bin/pip install bpy   # Blender як Python-модуль (Python 3.13)
.venv/bin/python build_scene.py dist
```

Або у встановленому Blender: `blender -b -P build_scene.py -- dist`.

Лише перевбудувати однофайловий переглядач після правок у `viewer/index.html`:

```bash
.venv/bin/python build_scene.py --embed dist/factory.glb dist
```

## Переглядач локально

GLB завантажується через `fetch`, тому `index.html` треба відкривати через
веб-сервер:

```bash
cd dist && python3 -m http.server 8000
# відкрити http://localhost:8000
```

`factory_viewer.html` можна відкрити просто подвійним кліком.

Керування: ліва кнопка миші обертає, права зсуває, коліщатко змінює масштаб.
Клік вибирає об'єкт, подвійний клік наближає до нього. Клавіші 1–9 і 0
перемикають види, Esc знімає вибір.

## Як влаштована сцена

- Кожен шар — порожній об'єкт `LAYER_<key>` у корені `FACTORY` (порядок у
  властивості `order`). Переглядач вмикає й вимикає шари за цими вузлами.
- Кожен клікабельний об'єкт має `code` (наприклад `FUR-R1-S02-L3`, `CNC-1`,
  `Z-SHEETS`). За цим кодом зручно пов'язати сцену із зовнішніми даними
  (склад, MES, ERP).
- Маячки верстатів позначені `role=status`: переглядач перефарбовує їх і
  блимає зупиненими.
- Маршрут виробу зберігається в extras об'єкта `FLOW` (`route`, JSON). За ним
  переглядач анімує точку, що біжить.
