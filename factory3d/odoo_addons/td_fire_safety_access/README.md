# td_fire_safety_access

Міст «Пожежна безпека × СКУД» (`auto_install`, залежить від `td_fire_safety` і `td_access`; власних моделей немає).

- Двері аварійних виходів `EX-*` у СКУД — кожен, хто вийшов, потрапляє в звіт навчальної тривоги: час евакуації,
  вихід за маршрутом зони й фактичний, не свій вихід.
- Після навчання блокування тривоги знімаються: двері `unlocked`/`open`, змінені навчанням, стають `locked`, пожежна
  тривога дверей знімається (`td.fire.drill._td_release_locks`, SPEC `td_fire_safety` R-16b).
- Тести: `/td_fire_safety_access`.
