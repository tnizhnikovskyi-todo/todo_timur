Access Telemetry Bridge

Seven access/* access-control signals in telemetry

What it does

Bridge between Factory Access Control and Factory 3D Telemetry, installed automatically when both are present.

Key features

  • Publishes seven access control signals as telemetry signals

Requirements

  • Works on Odoo 19 Community and Enterprise; no Enterprise module is required.
  • Factory 3D suite modules: Factory Access Control (td_access), Factory 3D Telemetry (td_telemetry).

Support

Part of the Factory 3D suite for Odoo 19. Questions and support requests: support@todo.ltd
