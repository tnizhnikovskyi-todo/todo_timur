# factory3d_yard

Двір підприємства: рейси сторонніх фур, бронювання воріт, LPR (Axis), шлагбауми, автоваги (SICS),
диспетчерська й екран КПП. Документація — `factory3d/docs/modules/factory3d_yard/`.

Стан: каркас (W0) — групи, меню, параметри `factory3d.yard.*`, послідовності, `tools/` (plate, tz, params).
Gantt — окремий міст `factory3d_yard_gantt` (потрібен `web_gantt`, Enterprise; DEC-1).

Тести: `factory3d/tools/odoo/run_tests.sh <db> /factory3d_yard`.
