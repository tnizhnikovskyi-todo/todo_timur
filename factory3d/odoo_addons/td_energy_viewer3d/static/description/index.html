Energy 3D Layer

Energy in 3D layer: node coloring by state, alarm markers, node card, jump from the console

What it does

Adds an Energy layer to the 3D viewer. It creates no data of its own; removing the module removes the layer.

Key features

  • Nodes of the power scheme colored by state
  • Alarm markers in the scene
  • Node card with live values
  • Jump from the Energy console to the 3D scene

Requirements

  • Works on Odoo 19 Community and Enterprise; no Enterprise module is required.
  • Factory 3D suite modules: Factory Energy (td_energy), Factory 3D Viewer (td_viewer3d).
  • Interface language: Ukrainian; an English translation is not included yet.
