Cogeneration Unit Console

Operator console for a gas cogeneration unit (CHP): live state, 3D model, mimic diagram, interlocks, commands, journal

What it does

A control-room screen for a TEDOM-type gas CHP unit. It reads the controller registers through the Factory 3D telemetry platform and shows the unit as a 3D model and as a layered mimic diagram, with KPI tiles, a 24-hour / 1-hour trend, cylinder diagnostics and an event journal with acknowledgement.

Key features

  • 3D model (37 nodes in 8 systems) and a six-layer mimic diagram with cross-layer links
  • 14 KPI tiles, trend for 24 h / 1 h, 16-cylinder diagnostics, maintenance by engine hours
  • Start, stop, emergency stop, reset and set-point commands with interlocks, two-person confirmation and a journal
  • Light and dark themes, works on a phone; without WebGL the 3D view is replaced by a placeholder
  • The 3D library (three.js r147) is bundled and loaded only when the console is opened

Requirements

  • Works on Odoo 19 Community and Enterprise; no Enterprise module is required.
  • Factory 3D suite modules: Factory 3D (td_factory3d) and Factory 3D Telemetry (td_telemetry).
  • The register map is a typical assumption and must be adjusted to the actual controller; the module does not replace the controller's own protections.
  • Writing to the controller is off by default (td.chp.write_enabled).
  • Interface language: Ukrainian; an English translation is not included yet.
