# Журнал змін

## 19.0.1.0.0 — перший випуск

- Моделі площадки, шарів, місць (шаблони стелажів → комірки), розміщень, варіантів обладнання, налаштувань перевірок, версій.
- Перевірки `fits`, `collide`, `service_free`, `aisles_free`, `load`, `utility_reach`, `fire` (OBB + SAT), золоті фікстури
  паритету з JS.
- Майстер публікації (збіг за `f3d_code`/`barcode`, без видалень, пропозиції архівації), знімки версій, відновлення чернетки.
- API-01…API-10: JSON-RPC, завантаження й віддача 3D-моделей; хук `_f3d_convert_model()` для STEP/IGES/IFC.
- Ролі технолог/комірник/інженер/менеджер, правила `ir.rule` + серверна перевірка шару.
- Seed «Меблеве підприємство» зі зв'язуванням наявних записів за кодом (`post_init_hook`).
- Шаблони комірок: додаткові параметри `index_digits`, `code_style` (`pallet_rack`), `loc_kind` (`shelf`) — щоб коди й види
  збігалися з уже наявними локаціями.
- Сід = уся 3D-модель переглядача: 31 шар (поле `group_name` — група у списку шарів) і всі 1078 кодованих об'єктів
  (`data/scene_inventory.json`, `tools/scene_inventory.py`; класифікація — `tools/scene_classify.py`, генерація —
  `tools/extract_seed.py`): стелажі-шаблони, одиночні місця (`code_style='exact'`, код комірки = код об'єкта), контури-зони,
  розміщення з автопаспортами «Об'єкти сцени» (роль `scene_<вид>`), люди й транспорт — `dynamic` (не беруть участі в
  collide/aisles/service/fire; публікація не створює для них обладнання).
- Знімок v1 «Імпорт із макета» містить `baseline.poses` — положення об'єктів, запечених у GLB (`{код: {x, y, z, L, W, H, yaw}}`;
  x, y — центр AABB, як `x_m`, `y_m` розміщень сіда): від них етап 2 рахує зсуви.
- `code_style='exact'` для всіх шаблонів з комірками: якщо шаблон дає рівно одну комірку, її код = `code_prefix`.
