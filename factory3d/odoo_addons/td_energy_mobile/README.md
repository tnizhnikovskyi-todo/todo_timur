# td_energy_mobile — Чергування (телефон)

Четверта вкладка «Обхід» мобільного екрана `td_energy.mobile` (3 вкладки W1 + «Обхід»), журнал обходів і події на відхилення.
Специфікація — `docs/modules/td_energy_mobile/SPEC.md` (Частина II), архітектура — `ARCHITECTURE.md` там само.

## Чергування
- Вхід «на телефон»: `/odoo/action-td_energy.action_td_energy_mobile` (меню «Енергетика → Чергування (телефон)») і
  «Додати на головний екран» (PWA Odoo). Екран адаптивний ≥ 360 px, кнопки ≥ 48 px.
- Вкладки: «Стан», «Тривоги · N», «Схема» (W1) та «Обхід» (цей модуль).

## Обхід
- Крон відкриває обхід за слотом шаблона (демо: «Обхід ТП і ГРЩ», «Зміна 1» 07:00–16:00, «Зміна 2» 16:00–23:00, пн–пт);
  «Запустити обхід зараз» (меню «Налаштування») — обхід «поза розкладом» на 2 години.
- Пункти — знімок шаблона. Підказка «норма до 85 °C · зараз 58 °C» береться з сигналу (`signal:<код>`) або KPI Пульту
  (`pult:<шлях>`); при відмітці зберігаються значення й результат («у нормі» / «поза нормою»).
- Виконавець — перший, хто відмітив; інший енергетик бачить «Обхід виконує {ім'я}» (лише читання), головний енергетик може
  завершити чужий. «Завершити обхід» вимагає всіх обов'язкових пунктів; відхилення → події «Обхід» у «Подіях».
- Слот минув, обхід не завершено → «Не виконано» й попередження (параметр `missed_event`).
- Журнал: «Енергетика → Журнал обходів» (читання; запис — лише методами). Шаблони: «Налаштування → Шаблони обходів» (головний енергетик).

## Параметри `td.energy_mobile.*`
| Параметр | За замовчуванням | Призначення |
|---|---|---|
| `keep_days` | 730 | зберігання обходів (ротація, крон раз на 7 діб) |
| `value_fresh_s` | 120 | сигнал «свіжий», якщо не старше (або 3 × період сигналу) |
| `missed_event` | 1 | створювати подію для не виконаного обходу |
| `history_limit` | 3 | скільки «останніх обходів» у вкладці |
