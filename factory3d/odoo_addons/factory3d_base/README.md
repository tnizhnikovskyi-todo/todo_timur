# factory3d_base

Ядро factory3d (Odoo 19): группы прав «Завод 3D», параметры `factory3d.base.*`, корневое меню.
Модели, зоны, паспорта и миграция добавляются следующими воркерами (см. docs/modules/factory3d_base).

Установка: `-i factory3d_base`. Параметры: меню «Завод 3D → Налаштування → Параметри системи».
