Constructor 3D Bridge

Viewer provider layout: shows the layout published in the Constructor on top of the 3D model

What it does

Bridge between Factory 3D Constructor and Factory 3D Viewer, installed automatically when both are present.

Key features

  • The viewer shows the layout published in the Constructor
  • Moved, added and removed objects are highlighted relative to the model

Requirements

  • Works on Odoo 19 Community and Enterprise; no Enterprise module is required.
  • Factory 3D suite modules: Factory 3D Constructor (td_constructor), Factory 3D Viewer (td_viewer3d).
  • Interface language: Ukrainian; an English translation is not included yet.

Support
