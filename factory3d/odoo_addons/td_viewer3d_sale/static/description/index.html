Factory 3D Viewer Sales

Show in 3D button on sales orders (bridge between the 3D viewer and Sales)

What it does

Small bridge between Factory 3D Viewer and Sales. It is installed automatically when both are present.

Key features

  • Adds the Show in 3D button to the sales order form
  • Opens the 3D viewer for the selected order

Requirements

  • Works on Odoo 19 Community and Enterprise; no Enterprise module is required.
  • Factory 3D suite modules: Factory 3D Viewer (td_viewer3d).
  • Odoo modules: sale.
  • Interface language: Ukrainian; an English translation is not included yet.

Support
