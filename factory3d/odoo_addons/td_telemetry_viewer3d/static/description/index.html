Telemetry 3D Bridge

Viewer provider: telemetry signal values in the 3D viewer payload

What it does

Bridge between Factory 3D Telemetry and the 3D viewer, installed automatically when both are present. It adds no models, data or menus.

Key features

  • Adds the values of telemetry signals to the viewer payload
  • Signal values become visible on the 3D objects they belong to

Requirements

  • Works on Odoo 19 Community and Enterprise; no Enterprise module is required.
  • Factory 3D suite modules: Factory 3D Core (td_factory3d), Factory 3D Telemetry (td_telemetry).
