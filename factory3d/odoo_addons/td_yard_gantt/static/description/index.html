Yard Gantt

Gantt view of gate bookings (requires web_gantt, Odoo Enterprise)

What it does

Adds a Gantt view to the gate bookings of Yard Management. It is installed automatically when Yard Management and the Enterprise web_gantt module are present.

Key features

  • Gantt view of gate bookings by gate and time

Requirements

  • Requires Odoo 19 Enterprise: depends on web_gantt (Enterprise).
  • Factory 3D suite modules: Yard Management (td_yard).
  • Odoo modules: web_gantt.
  • Interface language: Ukrainian; an English translation is not included yet.
