Завод 3D: переглядач

Цех, склад і виробництво в тривимірній моделі — з живими даними Odoo

Показати в 3D

Майстер, комірник, механік.

  1. Відкрийте форму МО, переміщення, робочого центру, місця зберігання, обладнання, співробітника, зони або замовлення клієнта.
  2. У шапці натисніть «Показати в 3D».
  3. Переглядач відкриється з вибраним об'єктом або маршрутом документа; у картці праворуч — ті самі дані, що на формі.
  4. Кнопка «← Назад» у Odoo повертає на форму.

З 3D у форму Odoo

Усі користувачі.

  1. Клацніть по об'єкту в сцені або по рядку в панелі.
  2. У картці натисніть «Відкрити в Odoo».
  3. Якщо запису в базі немає (інженерний об'єкт без моделі), з'явиться повідомлення, переглядач лишається відкритим.

Екран у цеху

Адміністратор, один раз на екран.

  1. Завод 3D → Налаштування → Налаштування переглядача → скопіюйте «URL кіоска».
  2. Додайте потрібні параметри: ?tab=production&mode=oee (дільниця), ?tab=overview&layers=prod (диспетчерська), &lite=1 для планшета.
  3. На планшеті відкрийте URL у Chrome і «Додати на головний екран» або закріпіть у Samsung Knox Kiosk.
  4. Якщо токен скомпрометовано — «Новий токен кіоска»; старі адреси перестануть працювати одразу, оновіть URL на екранах.

Програвання зміни

Менеджер, майстер.

  1. У переглядачі натисніть ▶ або тягніть повзунок 07:00–15:30.
  2. Якщо на цей день є знімки (Завод 3D → Журнал станів), повзунок показує реальні стани на той час; якщо ні — план за датами завдань (позначка «план» біля часу).
  3. «Зараз» повертає до живих даних.

Перевірка циклу

Менеджер.

  1. Завод 3D → Перевірка циклу → «Запустити».
  2. «Цикл замкнений» — усе гаразд; інакше список проблем, кожен рядок відкриває документ або об'єкт.
  3. Типові причини: приймання без воріт (немає пакетного переміщення з доком), відвантаження з рядками, що не збігаються із замовленням, компонент МО без шляху (немає приймання цього товару).

Демо-дані на тестовому сервері

Адміністратор.

  1. Переконайтесь, що це не прод (у налаштуваннях «Заливка демо дозволена» увімкнена лише на тесті).
  2. Завод 3D → Демо-дані → «Запустити всі кроки» (або оберіть кроки).
  3. Майстер працює у фоні 10–20 хв; прогрес і лог — у тому ж вікні («Оновити»).
  4. Повторний запуск нічого не дублює.
