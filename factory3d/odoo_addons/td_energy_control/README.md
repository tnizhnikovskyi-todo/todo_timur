# td_energy_control — Енергетика: Керування

Новий модуль W2 блоку «Енергетика» (`depends`: `td_energy`, `td_telemetry`, `td_bms`; LGPL-3, `application=False`).
Сценарії автоматики (виконує збирач `td_collector_energy`), пріоритети скидання, ручні команди класів A/B з
блокуваннями й підтвердженням, розклад, журнал.

Документація: `factory3d/build/energy/W2_SPEC.md`, `W2_ARCH.md`. **Заморожені JSON-контракти** C-38…C-47 —
`contracts/` (зміни лише через менеджера). Видалення модуля видаляє його дані як у будь-якого модуля Odoo
(D-45: архівних таблиць немає).
