Шлях: `package/release-plan-X.Y.md`; шаблон — `package/templates/release-plan.md`.
Файл з `where` наряду; backlog.md скіл **не змінює** (власник — backlog-triage).
Нумерація: X — несумісні зміни або нова версія Odoo; Y — нові функції.
