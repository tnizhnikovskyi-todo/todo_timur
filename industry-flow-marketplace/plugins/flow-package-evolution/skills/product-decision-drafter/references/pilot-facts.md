# Як отримати факти пілота (D-05)

Основне джерело — `clients/<клієнт>/hypercare.md@sha`, розділ «Факти для рішення по пілоту» (його пише `support-desk`, B-09;
формат — `flow-client-delivery/skills/support-desk/references/hypercare-template.md`). Читати з hypercare.md лише цей розділ
і лічильники за типами; вміст звернень, імена, листи не переносити.

## Передумова
Оркестратор ставить D-05 лише після B-09: у наряді `params.pilot: true` і є `hypercare.md@sha` з цим розділом. Стадію задачі B-09
через odoo-mcp **не читати**. Розділу немає -> `result: returned` на B-09.

## Години
- Беруться з розділу «Факти для рішення по пілоту» (години PM з табеля). Значення «очікує PM» або порожньо -> «немає факту»,
  `escalated` Власнику продукту, питання PM.
- Звірка з Odoo — необов'язкова, лише коли `flow/ODOO_SCHEMA.md@sha` (з `inputs` наряду) називає модель і поля табеля, а в наряді є
  `odoo_connections: [{alias: flow, purpose: наряд/звіт}]`. Тоді один виклик: `list_odoo_connections`, далі `odoo_search_read` з
  явним `connection_id`, моделлю й доменом за проєктом пілота з `ODOO_SCHEMA.md`, `fields` лише години/проєкт/дата (без
  співробітника й користувача), або `formatted_read_group` із сумою годин. `odoo_execute` для інших методів, `read_group` (застарів
  в Odoo 19) і будь-який запис — заборонено. Розбіжність з hypercare.md — рядок у «Відкриті питання», не вибір «зручнішого».
- Модель не названа в `ODOO_SCHEMA.md` -> Odoo не викликати, працювати лише з hypercare.md (відкрите питання В-2).
- Посилання на факт: `[джерело: clients/<к>/hypercare.md@<sha7>#Факти для рішення по пілоту]`; зі звірки — `[табель Odoo: задача <id>]`.

## Доробки
Кількість рядків із рішенням «доробка» у `fit-gap.md` (колонка «Рішення» таблиці вимог; також «Вимог класу «доробка»: N» у розділі
«Факти для пілоту»). Формат — `flow-client-delivery/skills/package-fit-gap/references/fit-gap-template.md`. Рахувати за колонкою
таблиці, не за вільним текстом.

## Інциденти
Лічильники за типами з розділу фактів hypercare.md; типи — спільна таблиця `flow-client-delivery/references/triage-routes.md`.
