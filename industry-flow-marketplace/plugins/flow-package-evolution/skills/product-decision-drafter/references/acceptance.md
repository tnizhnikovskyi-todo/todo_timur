## Тип причини -> код повернення (пропозиція, рішення за людиною)
| Тип причини | Ознака | Код |
|---|---|---|
| Невідповідність ТР/AC | AC неточний, суперечить іншому AC, сценарій перевіряє не те, чого вимагає ТР | A-08 |
| Дефект реалізації (код, конфіг, майстер-дані) | AC коректний, сценарій не проходить через пакет | A-14 (далі повтор A-15 -> A-16 -> A-17) |
| Немає підстави | немає рядка в CHECKS.md і сценарію | статус «не підтверджено», код не ставити |
