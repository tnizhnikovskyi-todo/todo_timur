Шлях: `package/ACCEPTANCE.md`; шаблон — `package/templates/ACCEPTANCE.md`. A-18 читає версію й SHA звідси. Формат таблиці AC
запозичено з `odoo19-implementation:acceptance-act-builder` (це внутрішнє приймання, не акт замовнику).

`package/upgrade-<версія>.md@sha`; version у addons/td_*/__manifest__.py; SHA з scenarios.md і README A-15.
