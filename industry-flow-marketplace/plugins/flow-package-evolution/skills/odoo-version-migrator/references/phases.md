## Стоп-умови
- `phase` відсутній; гілка не за regex або merge-base не збігається з тегом; тега A-18 немає -> `escalated` Тімліду.
- Клієнтський alias або прод у allow-list -> стоп.
- Немає доступу до release notes N -> `escalated` (нічого не вигадувати).
- C-00 без параметра версії або C-03 не параметризовано на N -> `escalated` AI-інженеру/Тімліду.
