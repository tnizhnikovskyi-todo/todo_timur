## Стоп-умови
- Гілка не за regex або merge-base не збігається з тегом; тега A-18 немає -> `escalated` Тімліду.
- Клієнтський alias або прод у allow-list -> стоп.
- Немає технічних джерел N (`odoo-src`, `odoo-src-19`) -> `escalated` Тімліду (нічого не вигадувати).
- C-00 без параметра версії або C-03 не параметризовано на N -> `escalated` AI-інженеру/Тімліду.


## Фаза за замовчуванням
`params.phase` -> `params.resume.params.phase` -> prepare.
