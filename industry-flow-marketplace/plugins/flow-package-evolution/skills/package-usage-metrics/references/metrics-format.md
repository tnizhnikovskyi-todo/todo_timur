# Формат метрик: `<клієнт>.yaml` і `<YYYY-MM>.md`

Заголовки `<YYYY-MM>.md` — grep-контракт для `flow-package-evolution:backlog-triage` (D-02) і перевірки M-11.
Клієнти в прикладах — вигадані коди `CL-01…`; у реальних файлах — код за розділом DATA_POLICY «Ідентифікатор клієнта в репозиторії».

## `package/metrics/<YYYY-MM>/<клієнт>.yaml` (collect)
```yaml
client: CL-01                    # код за DATA_POLICY, не назва юрособи
tag: package/v1.1                # git-тег пакета в клієнта (з поля проєкту)
period: {month: 2026-12, start: "2026-12-01T00:00:00Z", end: "2027-01-01T00:00:00Z"}   # end не включно
go_live: 2026-10-05
connection_alias: prod-metrics-CL-01   # без хоста, бази й логіна
active_internal_users: 14        # або null, якщо домен не підтверджений (тоді поле note)
models:
  - {model: td_order, source: td, in_tag: true, created: 120, changed: 340, status: ok}
  - {model: sale.order, source: key, in_tag: true, created: 80, changed: 210, status: ok}
  - {model: td_quality_check, source: td, in_tag: true, created: null, changed: null, status: absent}
  - {model: td_report_log, source: td, in_tag: true, created: null, changed: null, status: error}
errors: [{model: td_report_log, code: access_denied}]   # лише код з collect-recipes.md, без тексту проду
```
Правила: лише числа, коди й ідентифікатори; `created`/`changed` = `null` для `absent`/`error`; `source`: `td` | `key`.

## `package/metrics/<YYYY-MM>.md` (report)
Обов'язкові заголовки (точні):
```
# Метрики використання пакета <YYYY-MM>
## Шапка
## Клієнти на супроводі
## Використання моделей пакета
## Живе / не живе
## Динаміка до попереднього місяця
## Меню й звіти пакета (версія 1: використання не вимірюється)
## Обмеження версії 1
## Перевірка Власником продукту
```
Вміст розділів:
- **Шапка**: місяць, період, SHA входів (стан, журнал рішень, `<YYYY-MM>/*.yaml`, `key-models.yaml`), поріг
  `min_records` і `live_share` з датою й автором рішення, перелік тегів клієнтів.
- **Клієнти на супроводі**: `код | тег | go-live | міс. на супроводі | активні користувачі | статус збору (ok/помилки)`.
- **Використання моделей пакета**: `модель | джерело | тег(и) | CL-01 (створено/змінено) | CL-02 … `; «у тегу немає» — окремий символ, не нуль.
- **Живе / не живе**: `модель | клієнтів у тегу | клієнтів, що використовують | частка | позначка`;
  позначка: `живе` | `не живе` | `рано оцінювати` | `різні теги` (додається до позначки).
- **Динаміка**: `модель | клієнт | було | стало | дельта`; або «перший період»; «змінилась версія» де тег змінився.
- **Меню й звіти**: перелік з тегом; колонка використання — «не вимірюється (версія 2, телеметричний модуль)».
- **Обмеження версії 1**: лише `search_count`; без «різних користувачів по моделі»; архівні записи не враховано (В-2);
  меню/звіти не вимірюються; `active_internal_users` може бути «не виміряно».
- **Перевірка Власником продукту**: ім'я, дата, коментар — порожньо, заповнює людина.
