## Формати
- ID: `FG-NN` (вимога), `FG-D02-NN` (запит), `REJ-NNN` (відкинуте; вимога `FG-NN` лишається у «Вимоги» з посиланням на `REJ-NNN`). Не перенумеровуються; знята вимога: «знято: причина».
- Джерело: `fathom:<recording_id>@hh:mm:ss`, `анкета:VP-xx` або `анкета:р.N`. Два джерела через `; `.
- Місце в пакеті: `VP-xx`, `td_<модуль>`, `CONFIG.md §<заголовок>`, `scenarios.md S-xx` або «немає в пакеті».
- Рішення: `з пакета` / `доналаштування` / `доробка`. Год: `мін–макс`; для «з пакета» без робіт — `0`.
- Тип запиту D-02: незрозуміле питання / відсутній варіант значення / залежна VP / функція відсутня.
- Хто оцінив: `AI-чернетка` або `BA`.
