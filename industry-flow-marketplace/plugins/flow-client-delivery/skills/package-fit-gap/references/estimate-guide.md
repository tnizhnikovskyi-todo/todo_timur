# Довідник оцінок (AI-чернетка; це оцінки, не норми)

Мета — не занижувати. BA підтверджує в PR; Керівник напряму перевіряє правдоподібність перед шлюзом.
Калібрування — за логікою `odoo19-tr-authoring:tr-effort-instruction` і `docs/калібрування-оцінки.md` проєкту,
якщо файл доступний; цей файл не вигадує нових норм і не заміняє їх.

## Правила
- Завжди діапазон мін–макс, цілі години. Сума по документу — за **макс**.
- До оцінки входить: технічне рішення, реалізація, тестування, інструкція користувачу (як у `tr-effort-instruction`).
- «З пакета» без робіт — `0`; якщо потрібне лише заповнення анкети — теж `0`.
- Немає аналога в довіднику або в минулих проєктах — діапазон ширший і примітка «немає аналога»; питання BA.
- Залежність між вимогами (одна доробка закриває кілька) — оцінка один раз у першому рядку, в інших «див. FG-NN», 0.
- Сума годин fit-gap = «факт для пілоту» (D-05), не ціна: ціну рахує `package-sow-builder`.
