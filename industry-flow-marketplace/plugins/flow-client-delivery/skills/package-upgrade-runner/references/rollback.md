# Відкат на тестовій базі

Виконує Тімлід (скіл нічого не відновлює). Скіл лише описує розділ «Відкат» у `upgrade-log.md`.

## Формат розділу
| Поле | Значення |
|---|---|
| Спосіб | відновлення знімка тестової бази до установки / повернення на попередній тег `<тег>` |
| Знімок до установки | є / немає (як створено — не відомо AI; питання Тімліду) |
| Хто виконує | Тімлід |
| Умова відкату | які U-xx FAIL (зламані доробки, дрейф, дефект пакета) |
| Що передати в B-12 | опис відкату для прод (лише опис); рішення про прод — людина |

Заповнюється, якщо є зламані доробки або дрейф (U-09). Чого не знаємо (наявність знімка, спосіб відновлення бази) —
писати як питання до Тімліда, не вигадувати. Для прод-бази дій не планувати.
