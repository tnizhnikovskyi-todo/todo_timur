# Режими runbook-executor

| Режим | Визначається з наряду | Пишемо | Не чіпаємо | Статус інциденту | Тег у проєкті |
|---|---|---|---|---|---|
| застосувати | `step: B-04`, `returned_from: null` | `config-log.md`; модулі тегу; тег у проєкті (`flow`) | `answers.yaml`, `package/`, користувачі | - | ставиться (якщо модулі = тег) |
| виправлення (б) | `step: B-13` або `returned_from` B-09/B-10; в `inputs` `hypercare.md`/`support-log.md` | рядок у «Виправлення» (`INC-<id>`); статус рядка інциденту | тег; решта журналу | «виправлено на тесті — передано в B-12» | не змінюється |
| виправлення (в) | `returned_from: B-11`; в `inputs` `upgrade-log.md` | рядки «Виправлення» (`UPG-NN`) | тег; `upgrade-log.md` | - | не змінюється |
| звірка | `step: B-08a`, або B-11 з підкроком звірки | `config-drift.md` | усе в базі (read-only) | - | не змінюється |

Переходи: (б) -> B-12 (поставка в прод, людина); (в) -> B-11 продовжує; звірка -> B-08a (`convergence.md`) / B-11
(чернетка переліку втраченого конфігу, підтверджує Тімлід).
Неоднозначність режиму -> `escalated` Тімліду. Ліміти режимів — з наряду, не з пам'яті.
Тип інциденту ((б)) перевіряється відтворенням, не довірою до поля; тип «навчання»/поза пакетом -> Підтримка / D-02.
