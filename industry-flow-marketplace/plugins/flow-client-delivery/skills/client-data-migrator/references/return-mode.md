# Режим повернення (B-08c / B-09 / B-10 -> B-06)

Умова: `returned_from` вказує на інцидент типу «дані» з реєстру (`acceptance-act.md`, `hypercare.md`, `support-log.md`).
Тип інциденту ставить тріаж (`support-desk`, `triage-routes.md`); цей скіл тип не змінює. Тип не «дані» -> `returned`
з причиною.

## Що робимо
1. Прочитати лише рядок інциденту за ID.
2. Визначити об'єкт: модель, external ID, кількість.
3. Виправити на `test-<к>` точковим `load`/`write` за external ID (дозавантаження — тим самим `transform.py`).
4. Дописати рядок у «Виправлення даних» плану.
5. Поставити в рядку інциденту статус «виправлено на тесті — передано в B-12» (лише це поле).

## Формат рядка «Виправлення даних»
`ID інциденту | джерело | що виправлено | external ID / модель / кількість | дата на тесті | підтвердження клієнта (порожньо — людина) | статус`

## Межі
- План, SOW, таблицю звірки і підпис тестового імпорту не змінювати; перебудови плану й нової вибірки — лише якщо
  потрібна нова структура (тоді memo і рішення PM).
- Поставка виправлення в прод — B-12 (людина); слів «застосовано в прод» не писати.
- 3 невдалі спроби -> PM (інцидент, спроби, помилки).
