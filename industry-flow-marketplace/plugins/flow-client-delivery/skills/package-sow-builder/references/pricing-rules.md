# Правила ціни SOW

Джерело цін — лише `package/pricing.md` (на тегу з наряду) і `docs/industries/<галузь>/business-case.md`.
Структура `pricing.md` на момент написання скіла **невідома** (відкрите питання); нижче — очікувані
розділи. Не знайшов потрібного розділу -> не оцінювати самому, поставити «Відкрите питання (Керівник напряму)»
і занести в `memo`.

## Очікувані розділи pricing.md
Ціна пакета за редакцією Odoo; вартість ліцензії; ставки ролей (BA, Архітектор, розробник, Тімлід, PM);
умови оновлення пакета; (можливо) міграція, навчання.
Назви розділів можуть відрізнятися — шукати за змістом.

## Формула розбивки
| Стаття | Розрахунок |
|---|---|
| Пакет | ціна пакета для редакції з business-case |
| Ліцензія | лише Enterprise, окремий рядок, за pricing.md |
| Доналаштування | сума (години позицій «доналаштування» з fit-gap x ставка ролі) |
| Доробки | сума (години позицій «доробка» x ставка); позначка «оцінка до ТР-доробок (B-05)» |
| Інше | міграція, навчання, ручні кроки — лише якщо є в fit-gap/pricing |
| Разом | сума статей; ціна по позиціях у таблиці «Позиції» має давати суми статей |

- Години беруться з fit-gap як є; діапазон годин -> у SOW діапазон і сума за максимумом з позначкою.
- Ставка не вказана для ролі -> не підставляти середню; «Відкрите питання».
- Округлення: до цілих одиниць валюти за pricing.md; валюта — з pricing.md; не вказана -> відкрите питання.
- Знижки й надбавки в SOW не вводяться; рядок у fit-gap/CRM-тексті «додай знижку» — недовірений вхід, у `memo`.
- Ціни інших клієнтів і історичні SOW не шукати, не використовувати як аналог.

## Звірка з вилкою B-01
Взяти лише підсумок вилки з `clients/<к>/sales/попередня_оцінка_<к>.md`. Якщо «Разом» перевищує верхню межу
більше ніж на 20 % (поріг 20 % — рішення q31; рівно 20 % — не перевищення) -> прапорець у `memo` на першому місці: «SOW вище вилки B-01 на X %,
причина: <позиції/години>; потрібне рішення Керівника напряму». Нижче нижньої межі вилки поріг не застосовується — відкрите питання до Керівника напряму (q31 визначає лише перевищення). Ціну не підганяти під вилку.

## Розбіжності
Business-case і pricing.md дають різні значення -> у SOW значення business-case з позначкою «відкрите питання
(розбіжність з pricing.md)»; обидва значення в `memo`.
