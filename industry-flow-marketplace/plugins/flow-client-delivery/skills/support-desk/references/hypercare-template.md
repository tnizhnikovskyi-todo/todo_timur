# Еталон `package/templates/hypercare.md` (B-09)

Використовувати, якщо шаблона на тегу пакета немає (memo: «шаблон не в пакеті»). Створюючи файл із шаблону, **не копіювати рядки-приклади** (вони нижче, поза шаблоном): реєстр починається порожнім.
Обов'язкові заголовки (grep-контракт): «Заголовний блок», «Реєстр інцидентів», «Запити в D-02»,
«Факти для рішення по пілоту» (лише для пілота), «Журнал запусків».
