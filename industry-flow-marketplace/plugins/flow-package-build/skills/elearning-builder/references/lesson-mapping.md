# З інструкцій A-16b до курсу

| Джерело (user-guide) | Елемент курсу |
|---|---|
| Файл `<роль>.md` | курс (`role: <роль>`); назва «Курс: <Роль>» |
| Розділ `## SC-NN <назва>` | урок (`source: <роль>.md#SC-NN`); назва = назва сценарію |
| Кроки таблиці `№ / Дія / Що видно` | текст уроку (непорожнє поле тексту; список кроків) |
| Знімок `img/<роль>/SC-NN-N.png` | зображення в уроці (обов'язкове, якщо розділ має знімки; EL-content) |
| «Типові помилки» розділу (джерело FAQ A-16b) | остання частина уроку або окреме питання тесту |
| Розділ «Статус: заблоковано дефектом» | урок не створюється (WARN EL-blocked), повернення A-14 |
| AC, пов'язані з SC-NN (`Пов'язані AC`) | основа питань тесту |
| `admin.md` | курс «Адміністратор»; параметри `answers.yaml` — питання про параметри, не про значення клієнта |
| Розділ `admin.md` (`## Перший запуск`, `## Параметри`, `## Профілі`, `## Редакції`, `## Користувачі й ролі`, `## Типові помилки`) | урок курсу «Адміністратор»: `source: admin.md#<заголовок>` (SC-NN не потрібен; `#SC-NN` — лише якщо в SPEC є адмін-сценарій) |

Питання тесту: 5–10 на курс; типи — «яка дія наступна», «де видно результат», «що робити при помилці», «що неправильно»; одна правильна відповідь,
дистрактори правдоподібні (з іншого сценарію ролі); пояснення правильної відповіді — у коментарі питання (поле пояснення — лише якщо підтверджено в 19.0).
Не питати про технічні імена моделей і SHA; не брати цифри/назви реальних клієнтів.
