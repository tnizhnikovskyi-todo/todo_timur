# Структура модуля `td_<галузь>_elearning`

```
td_<галузь>_elearning/
  __init__.py
  __manifest__.py        # depends: ['website_slides'] (+ 'website_slides_survey' лише після підтвердження у 19.0)
  README.md              # джерела звірки 19.0 (файл:рядок); рядки «Механізм порога:» і «Доступ:» (EL-score, EL-access)
  data/
    params.xml           # ir.config_parameter: *.pass_score (з answers.yaml elearning.pass_score, за замовчуванням 80)
    courses_<роль>.xml   # курс ролі + уроки + урок-тест + питання + відповіді (або один courses.xml)
  static/img/<роль>/     # копії знімків з package/docs/user-guide/img/<роль>/ (SC-NN-N.png)
  tests/
    __init__.py
    test_courses.py      # установка, курсів = ролей (за xml-id), >=5 питань на курс, поріг, доступ (test_*access*)
```

Правила:
- Ім'я модуля — `td_<код галузі>_elearning` (код з пакета, напр. `td_mebli_elearning`); версія модуля = `19.0.<X.Y інших td_* пакета>.0` (їхні маніфести однакові; не 1.0 за замовчуванням), далі за `package-release-builder/references/versioning.md` (R-03).
- Маніфест: `license` як у решти `td_*` пакета (A-11), `depends` мінімальний; `data` — у порядку params -> курси.
- Усі `id` записів — локальні (`course_<роль>`, `lesson_<роль>_<n>`, `test_<роль>`, `q_<роль>_<n>`, `a_<роль>_<n>_<m>`); посилання `ref` — на ці id.
- Параметра `mode` у модулі немає: `elearning.mode: "off"` = модуль не збирається (крок A-17b не запускається).
- README.md містить рядки (їх читає `check_elearning.py`):
  `Механізм порога: штатний|survey|код <файл:рядок 19.0>` і `Доступ: <хто бачить курси> <файл:рядок 19.0>`.
- Урок має текст кроків і зображення з розділу A-16b у полях, підтверджених у 19.0 (EL-content).
- Коментарі-маркери всередині `<record>`: `role: <роль>` (курс), `source: <роль>.md#SC-NN` (урок), `multi: true` (питання); їх читає `check_elearning.py`.
- Імена моделей і полів у прикладі — **чернетка**; перед використанням звірити з вихідниками 19.0 (`source-verification.md`).
- Дані `noupdate="1"`, щоб оновлення модуля не затирало правки клієнта (B-07 адаптує курси на клієнті).
- Без даних клієнтів; демо-користувачів курси не створюють.

## Оновлення версії пакета й поріг клієнта
- Дані `noupdate="1"`: уроки й питання вже встановленого клієнта при оновленні модуля **не перезаписуються** (правки клієнта, адаптація B-07 зберігаються). Оновлені уроки нової версії пакета (після refresh A-16b) потрапляють до нових установок; до існуючих клієнтів їх доносить `package-upgrade-runner` (B-11) лише за явним рішенням: як саме (оновлення записів вручну, окремий data-файл, повторне завантаження) — **«Відкрите питання»**, рядок у `research/AI-DECISIONS.md` («перевірити: механізм оновлення курсів на встановленому клієнті»), механізм не вигадується.
- `pass_score` у `data/params.xml` фіксується на збірці пакета (EL-pass = збіг з `answers.yaml` пакета). Поріг для конкретного клієнта змінюється значенням `ir.config_parameter` `td_<галузь>_elearning.pass_score` на B-04/B-07 (посилання на `vp-map` або «Відкрите питання», якщо параметр не віднесено до VP); непідтверджений шлях — рядок AI-DECISIONS.
