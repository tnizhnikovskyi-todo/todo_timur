# Що звірити у вихідниках Odoo 19.0 (до написання XML)

Правило: кожен пункт — файл:рядок у гілці `19.0` (GitHub odoo/odoo; Grep по `addons/website_slides`, `addons/website_slides_survey`, потім Read 50–100 рядків).
Результат — таблиця в `README.md` модуля й `data_sources` звіту; «не знайдено» -> можливість не використовується, рядок у `research/AI-DECISIONS.md` («перевірити у вихідниках 19.0: …», ризик).

| № | Що підтвердити | Де шукати | Якщо не підтверджено |
|---|---|---|---|
| 1 | Моделі `slide.channel`, `slide.slide`, `slide.question`, `slide.answer` існують у 19.0 | `website_slides/models/` | зупинка, `escalated` Архітектору |
| 2 | Поля зв'язків (урок -> курс, питання -> урок, відповідь -> питання), прапорець правильної відповіді, текст відповіді | ті самі моделі | не використовувати |
| 3 | Обов'язкові поля курсу й уроку, тип уроку (стаття/тест), де вводиться текст/зображення | `slide_channel.py`, `slide_slide.py` | не використовувати |
| 4 | Як рахується результат тесту (бали, спроби); чи є штатний поріг проходження | `slide_slide.py`, `slide_question.py` | поріг лише параметром, «не перевірено» |
| 5 | `website_slides_survey`: чи є в ядрі CE 19.0, що дає (сертифікат, прив'язка опитування), залежності | `addons/website_slides_survey/__manifest__.py` | сертифікація не робиться, «не перевірено» |
| 6 | Як приховати/не публікувати курс (для `elearning: off`) | поля публікації/доступу `slide.channel` | `off` = «не перевірено», механізм не вигадується |
| 7 | Права: хто бачить курси (групи), чи потрібен website-модуль | `security/` | зафіксувати у README |

Тести не доводять наявність поля в 19.0 — їх запуск (EL-install) підтверджує лише те, що модуль встановлюється. Неможливо звірити (немає доступу до вихідників) -> «не перевірено», стоп без вигадування.
