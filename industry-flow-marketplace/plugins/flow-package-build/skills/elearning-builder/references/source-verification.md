# Що звірити у вихідниках Odoo 19.0 (до написання XML)

Порядок джерел: (1) локальні вихідники Odoo 19, з яких піднято стенд A-15 (шлях — `package/demo/README.md` або `tools/odoo`); (2) якщо їх немає — GitHub odoo/odoo, гілка `19.0`. Правило: кожен пункт — файл:рядок (Grep по `addons/website_slides`, `addons/website_slides_survey`, потім Read 50–100 рядків). У `data_sources` звіту й `README.md` модуля вказати, яке з двох джерел використано, і версію/коміт (`git -C <шлях> rev-parse HEAD` або SHA гілки 19.0).
Результат — таблиця в `README.md` модуля й `data_sources` звіту; «не знайдено» -> можливість не використовується, рядок у `research/AI-DECISIONS.md` («перевірити у вихідниках 19.0: …», ризик).

| № | Що підтвердити | Де шукати | Якщо не підтверджено |
|---|---|---|---|
| 1 | Моделі `slide.channel`, `slide.slide`, `slide.question`, `slide.answer` існують у 19.0 | `website_slides/models/` | зупинка, `escalated` Архітектору |
| 2 | Поля зв'язків (урок -> курс, питання -> урок, відповідь -> питання), прапорець правильної відповіді, текст відповіді | ті самі моделі | не використовувати |
| 3 | Обов'язкові поля курсу й уроку, тип уроку (стаття/тест), де вводиться текст/зображення | `slide_channel.py`, `slide_slide.py` | не використовувати |
| 4 | Як рахується результат тесту (бали, спроби); чи є штатний поріг проходження; чи є поле порога у `website_slides_survey` | `slide_slide.py`, `slide_question.py`, `website_slides_survey/` | дерево рішень Кроку 1: механізм «код» (відсоток проти `pass_score` + тест); «параметр без механізму» = не готово |

| 6 | Не застосовується: `elearning.mode: "off"` = модуль не збирається, параметра `mode` у модулі немає | — | — |
| 8 | Залежності `website_slides` (`__manifest__.py`, файл:рядок) і наслідки установки: `website`, `website_mail`, `website_profile`, `portal_rating` -> застосунок «Вебсайт», корінь `/` стає сайтом, портал і меню сайту | `website_slides/__manifest__.py` | рядок AI-NN з ризиком (власник — вето) |
| 7 | Хто бачить курси: поля публікації/доступу `slide.channel` (`enroll`, видимість), групи, `security/` — курси не мають бути публічними | `slide_channel.py`, `security/` | EL-access: доступ не підтверджено = не готово, рядок AI-DECISIONS |

Тести не доводять наявність поля в 19.0 — їх запуск (EL-install) підтверджує лише те, що модуль встановлюється. Неможливо звірити (немає ні локальних вихідників, ні доступу до GitHub 19.0) -> «не перевірено», стоп без вигадування; відсутність лише одного з двох джерел — не причина зупинки.
