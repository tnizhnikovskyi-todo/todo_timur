# Вендоринг «готове в складі конфіг-пакета»

Лише рядки ALLOCATION зі способом установки «в складі конфіг-пакета». Спосіб «залежність td_*» -- A-11, сюди не належить.

Каталог `package/addons/<модуль>/`:
- `__manifest__.py`: `version` починається з `19.0.`; залежності -- в `manifest.yaml` порядок «після залежностей, до налаштувань»;
- `LICENSE` -- текст ліцензії джерела;
- `README.md` -- джерело (URL/репозиторій), **коміт**, ліцензія, дата вендорингу, перелік локальних змін (бажано жодних);
- `boost:odoo19-lint` проходить.

Не вендорити (ескалація Тімліду): джерело невідоме, коміту немає, ліцензія несумісна або не визначена, модуль не під 19.0.
