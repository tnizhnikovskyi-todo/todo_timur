# Шаблон сторінки KB

Файл `kb/KB-NNN-<slug>.md`; `kind` — одне з `module | diagnostics | faq | limits | architecture`. Заголовок `# KB-NNN <назва>`, потім `kind:` (і `module:` для module) окремими рядками.

```markdown
# KB-NNN Модуль td_<імя>
kind: module
module: td_<імя>
SHA: <sha>   Джерело: package/addons/td_<імя>/ ; SPEC §<розділ>

## Призначення
<1–3 речення з SPEC; яку біль закриває>

## Моделі й ключові поля
| Модель | Поля | Звідки (файл:рядок) |
|---|---|---|

## Доступ і групи
<групи td_*, що бачить кожна роль>

## Параметри
| Параметр | Де (answers.yaml / VP-xx / ir.config_parameter) | За замовчуванням | Що змінює |
|---|---|---|---|

## Поведінка, яку підтримка бачить як «дивну, але нормальну»
- <спостереження> (джерело)

## Відомі обмеження й ризики
- <обмеження> — AI-NN (посилання на AI-DECISIONS)

## Зв'язані сторінки
KB-NNN (діагностика), `<роль>.md#SC-NN`.
```
Правила: кожен рядок про поведінку має джерело (файл:рядок, SPEC або AI-NN); невідоме — «Відкрите питання»; без даних клієнтів.
