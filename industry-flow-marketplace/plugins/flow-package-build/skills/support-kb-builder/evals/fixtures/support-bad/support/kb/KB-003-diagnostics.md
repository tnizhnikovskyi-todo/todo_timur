# KB-003 Діагностика
kind: diagnostics

### DG-01 Не видно деталей у виробничому замовленні
- Симптом: у MO немає вкладки деталей.
- Перевірка: чи встановлено td_mebli_core, чи є група.
- Виправлення: додати групу користувачу.
- Маршрут: B-13 (B-05)

### DG-02 Користувач не знає, як прийняти плиту
- Симптом: питання «як прийняти».
- Перевірка: розділ SC-01 посібника.
- Виправлення: відповісти за KB.
- Маршрут: розібратись пізніше
