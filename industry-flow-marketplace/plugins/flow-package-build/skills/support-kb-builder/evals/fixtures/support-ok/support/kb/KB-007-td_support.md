# KB-007 Звернення з td_support
kind: diagnostics

Лист від td_support: тема `[ToDo-support][<uuid бази>] <текст>`, у тілі трасування, URL без параметрів, версія, модулі, згода користувача.

### DG-10 Виняток у модулі td_ у листі td_support
- Симптом: лист із трасуванням, останній рядок у `td_mebli_core`.
- Перевірка: версія пакета з листа проти config-log.md; чи відтворюється на демо-стенді пакета.
- Виправлення: передати розробнику; AI лише пропонує.
- Маршрут: B-13 (B-05)

### DG-11 Виняток у стандартному модулі Odoo
- Симптом: лист із трасуванням у стандартному модулі.
- Перевірка: налаштування за config-log.md.
- Виправлення: правка конфігу людиною.
- Маршрут: B-13 (B-04)

### Службові приклади
- Адреса підтримки за замовчуванням у `views/res_config_settings_views.xml`: `support@example.com` (заглушка, не реальний email).
- Реєстр клієнтів: загальний `clients/REGISTRY.md` (посилання допустиме).
