# Посібник адміністратора

## Перший запуск
Модулі до установки — `package/config/CONFIG.md` (порядок і джерело). Команда установки пакета — з README пакета (не вигадувати).
Пароль демо-ролей не наводити: лише назву змінної (`DEMO_USERS_PASSWORD` — «задайте перед `up.sh`»); значень паролів, токенів і секретів у посібнику немає (перевірка `no-pii`).
Після установки: <перевірка: що має бути видно>.

CE — повний посібник. EE — що додається/змінюється; без доступу до EE: «не перевірено» (не писати як факт).

## Користувачі й ролі
Групи доступу `td_*` і стандартні; як призначити роль користувачеві (підписи UI зі стенда).
