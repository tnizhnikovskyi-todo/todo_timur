# Шаблон картки-шпаргалки (`cards/<роль>.md`)

Одна сторінка A4 на роль: ≤ 45 непорожніх рядків (UG-card). Без знімків (їх немає на картці; посилання на розділ — є).

```markdown
# Картка: <Роль>

Повний посібник: ../<роль>.md

## SC-01 <назва>
1. Відкрийте «<Меню>» -> «<Підменю>».
2. Натисніть «<Кнопка>», заповніть «<Поле>».
3. Натисніть «<Зберегти>». Готово, коли статус «<Статус>».

## SC-02 <назва>
...

## Якщо не виходить
- «<Симптом>» -> <дія>. Інакше — до підтримки: <канал з SOW клієнта>.
```
Кроки картки повторюють кроки розділу (без розбіжностей), підписи — українські (UG-lang).
