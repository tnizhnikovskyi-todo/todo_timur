# Зйомка знімків для інструкцій

1. **Стенд.** Піднятий A-15 на SHA модулів (`package/demo/README.md`); перед зйомкою кожної ролі — скидання до чистого стану
   скриптом скидання з `package/demo/` (за тегом/профілем). Не відновлювати з бекапу бази, що лежить у git (бінарники баз у PR — FAIL).
2. **Користувач.** Демо-користувач саме цієї ролі (з README стенда); знімок під ролю адміністратора для `admin.md`.
3. **Що знімати.** Ключовий результат кроку: список, форма до/після збереження, повідомлення, статус. Не весь екран, якщо
   фрагмент зрозуміліший; без адресного рядка з токенами/паролями; мова UI — українська.
4. **Ім'я.** `img/<роль>/SC-NN-<крок>.png` (крок — ціле число, як у таблиці). Розмір — до ~300 КБ на файл (стискати без втрати читабельності).
5. **Журнал.** `img/SHOOT-LOG.md`: `файл | SHA | дата | демо-користувач | стенд`. UG-fresh (MANUAL): усі рядки мають SHA = INDEX.
6. **Дані.** Лише синтетика стенда; перед комітом переглянути знімки: немає реальних назв, ПІБ, телефонів, email, токенів.
7. **Засіб зйомки** — той, що вже є в A-16 (тури) або `package/demo/`. Якщо в турах немає знімків — запис у «Відкриті питання»
   звіту; не вигадувати інструмент і його ключі.
8. **Після виправлення дефекту** (A-14 -> A-11 -> A-15): режим `refresh` — перезняти лише сценарії, що зачеплено; оновити SHA в INDEX і SHOOT-LOG.
