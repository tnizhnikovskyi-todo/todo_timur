# Зйомка знімків для інструкцій

1. **Стенд.** Піднятий A-15 на SHA_STAND (`package/demo/README.md`; свіжість — `git diff --quiet <SHA_CHECKS>..HEAD -- package/addons package/config package/master-data ':!package/addons/td_*_elearning/*' ':!package/config/manifest.yaml' ':!package/config/CONFIG.md'`); перед зйомкою кожної ролі — скидання до чистого стану
   скриптом скидання з `package/demo/` (за тегом/профілем). Не відновлювати з бекапу бази, що лежить у git (бінарники баз у PR — FAIL).
2. **Користувач.** Демо-користувач саме цієї ролі (з README стенда); знімок під ролю адміністратора для `admin.md`.
3. **Що знімати.** Ключовий результат кроку: список, форма до/після збереження, повідомлення, статус. Не весь екран, якщо
   фрагмент зрозуміліший; без адресного рядка з токенами/паролями; мова UI — українська.
4. **Ім'я.** `img/<роль>/SC-NN-<крок>.png` (крок — ціле число, як у таблиці). Розмір — до ~300 КБ на файл (стискати без втрати читабельності).
5. **Журнал.** `img/SHOOT-LOG.md`: `файл | SHA | дата | демо-користувач | стенд`. UG-fresh (MANUAL): усі рядки мають SHA = INDEX.
6. **Дані.** Лише синтетика стенда; перед комітом переглянути знімки: немає реальних назв, ПІБ, телефонів, email, токенів.
7. **Засіб зйомки** — за замовчуванням Playwright (headless Chromium): `scripts/shoot.mjs` скіла (план `package/docs/user-guide/shoot-plan.json`: адреса стенда, демо-логін ролі, SC-NN -> URL/кроки з турів A-16; пароль з env `DEMO_USERS_PASSWORD` (або змінна з `password_env` плану)) або `flow-research/skills/prototype-builder/scripts/rec_lib.mjs` (той самий Playwright, що в A-21). Засіб у `package/demo/` — якщо вже є. Скрипт сам додає рядки в `SHOOT-LOG.md`. Селектори й адреси беруться з турів A-16/SPEC, а не вгадуються; перший прогін перевіряє їх на стенді. Браузер не запускається (код 2 скрипта) -> рішення AI з ризиком (AI-NN) і `waiting_human`; інструмент не вигадувати, знімки не малювати.
8. **Після виправлення дефекту** (A-14 -> A-11 -> A-15): режим `refresh` — перезняти лише сценарії, що зачеплено; оновити SHA в INDEX і SHOOT-LOG.
