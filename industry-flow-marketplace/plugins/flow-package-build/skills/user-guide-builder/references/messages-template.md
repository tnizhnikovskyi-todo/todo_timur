# Шаблон `reference/messages.md` — довідник повідомлень системи (0.4.1)

Файл `package/docs/user-guide/reference/messages.md`. Усі тексти `UserError`, `ValidationError`, `AccessError` з модулів `td_*`
(без `td_*_elearning`, `td_*_demo`, tests) **дослівно з `msgstr` uk.po модуля** (не з коду й не перекладені заново). Перевіряє UG-messages
(`check_guides.py --addons …`): кожен текст із коду має рядок у довіднику (missing 0), у рядку заповнені 4 поля, посібники ролей і `admin.md`
посилаються на довідник (`reference/messages.md`).

```markdown
# Повідомлення системи: довідник помилок пакета

Опис: усі повідомлення про помилки модулів `td_*`; `%s`, `%(…)s` — місце підстановки назви, числа чи дати. Стандартні повідомлення Odoo не наводяться.
Ролі й посібники: <роль> — `<роль>.md`, … Незрозуміла помилка — кнопка «Надіслати в підтримку ToDo» (`td_support`).

## <модуль td_*>
| Повідомлення (дослівно) | Коли виникає | Що робити | Хто виправляє | Джерело |
|---|---|---|---|---|
| «<текст з msgstr uk.po>» | <дія користувача, після якої з'являється> | <крок користувача> | <роль / адміністратор / ToDo> | `td_x/models/m.py:11` |
```
Правила:
- Текст у «ялинках», символ `|` у тексті замінюється на `/`, перенос рядка — на пробіл (так само порівнює скрипт).
- «Хто виправляє»: роль користувача (зміна даних), адміністратор (права, канали, параметри), ToDo (дефект) — не порожнє.
- Повідомлення без `msgstr` у uk.po -> рядок з текстом коду + дефект перекладу пакета в `package/demo/defects.md` (WARN скрипта).
- Джерело — файл:рядок у `td_*` (допомагає refresh після змін модулів).
