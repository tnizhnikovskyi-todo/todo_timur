# Посібник: Комірник

## SC-01 Прийняти плиту
Коли: щодня.
Статус: готово

| № | Дія | Що видно |
|---|---|---|
| 1 | Відкрийте «Склад меблів», далі «Обмін з BAS» | ![Крок 1](img/komirnyk/SC-01-1.png) |
| 2 | Відкрийте «Налаштування → Технічні → Системні параметри», потім «Склад меблів» | ![Крок 2](img/komirnyk/SC-01-1.png) |
| 3 | Відкрийте Налаштування → Технічні → Системні параметри | ![Крок 3](img/komirnyk/SC-01-1.png) |
| 4 | Перейдіть: **Налаштування → Технічні → Системні параметри** | ![Крок 4](img/komirnyk/SC-01-1.png) |

Типові помилки: «Спершу завантажте файл.» — див. довідник.
