# Налаштування довідників і товарів

Виконує адміністратор (технолог). Знімки зроблено під його логіном.

## 1. Замовлення клієнта (`sale.order`)
- **Хто:** адміністратор.
- **Де в меню:** Продажі → Замовлення → форма замовлення, вкладка «Розміри».
- **Кроки:**
  1. Відкрийте меню «Продажі → Замовлення» і натисніть «Створити».
  2. Введіть ширину в поле `td_width` і глибину в `td_depth` у міліметрах.
- **Обов'язкові поля:** `td_width`, `td_depth` — видно на вкладці «Розміри».
- **Типова помилка:** розмір порожній — розкрій не рахується; заповніть обидва поля.
- **CSV-шаблон:** немає: замовлення створюють вручну, масового імпорту не потрібно.

![Форма замовлення](img/admin/SETUP-01-1.png)

## 2. Матеріали (`td.x.material`)
- **Хто:** технолог.
- **Де в меню:** Матеріали (дія «Матеріали»).
- **Кроки:**
  1. Відкрийте меню «Матеріали» і натисніть «Створити».
  2. Введіть назву та густину.
- **Обов'язкові поля:** назва, `td_density`.
- **Типова помилка:** дубль назви — перевірте список перед створенням.
- **CSV-шаблон:** `templates/td.x.material.csv` — імпорт через «Імпортувати записи».

![Список матеріалів](img/admin/SETUP-02-1.png)

## Не довідники
| Модель | Чому не довідник |
|---|---|
| `td.x.repair` (дія «Ремонти») | це документ зі станом, а не довідник |

## Межі налаштування
Без коду не налаштувати: параметри виробу лише з переліку полів форми, ціна — одна формула (рядок AI-NN «межі»).
