# Посібник: Комірник

## SC-01 Прийняти плиту
Коли: щодня.
Статус: готово

| № | Дія | Що видно |
|---|---|---|
| 1 | Відкрийте «Склад меблів» | ![Крок 1](img/komirnyk/SC-01-1.png) |
| 2 | Відкрийте «Сканувати етикетки» | ![Крок 2](img/komirnyk/SC-01-2.png) |
| 3 | Кнопку «Скасувати підтверджені» комірник не бачить: її натискає керівник | ![Крок 3](img/komirnyk/SC-01-3.png) |
| 4 | Відкрийте «Reporting» → «Звіт один» (Command.link додав групу керівника) | ![Крок 4](img/komirnyk/SC-01-1.png) |
| 5 | Відкрийте «Звіт два» (замінено на закупівника) | ![Крок 5](img/komirnyk/SC-01-1.png) |
| 6 | Відкрийте «Звіт три» (групу знято) | ![Крок 6](img/komirnyk/SC-01-1.png) |
| 7 | Відкрийте «Звіт чотири» (додано групу підпису) | ![Крок 7](img/komirnyk/SC-01-1.png) |
| 8 | Відкрийте «Обмін з BAS». Меню «Сканувати етикетки» комірник не бачить | ![Крок 8](img/komirnyk/SC-01-1.png) |

Типові помилки: «Спершу завантажте файл.» — див. довідник.

Повідомлення системи — `reference/messages.md`.
