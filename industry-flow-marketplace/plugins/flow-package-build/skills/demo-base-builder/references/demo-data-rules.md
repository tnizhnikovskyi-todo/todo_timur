# Правила синтетичних демо-даних (обидва режими)

Джерело орієнтирів обсягів і порядку наповнення — `odoo19-sales-prep:demo-build-plan` (контракт «Порядок наповнення», рівень бази 1);
конкретні цифри для галузі скіл бере з ТР/plan.md, а де їх немає — позначає «орієнтир, узгодити з Тімлідом». Тут цифри не вигадуються.

## Синтетика
- Назви компаній, товарів, складів — з префіксом «Демо-» (`Демо-Постачальник 01`). Реальні назви з ТР, AIKB, Fathom, Drive, відкритих реєстрів — заборонені.
- Люди: ролі замість ПІБ (`Демо Менеджер продажів 1`); реальних ПІБ немає.
- E-mail лише `*@example.com`; телефони лише з резервного/вигаданого діапазону: розділ «Синтетичні контакти для демо» `package/DATA_POLICY.md`
  (пропозиція до `flow-core/references/data-policy-template.md`, В-10). Розділу немає — використовувати вигаданий діапазон, що явно
  не існує (`+380 00 000 00 NN`), записати його в README і в `memo` одним рядком для Тімліда; не зупиняти крок.
- Коди ЄДРПОУ/ІПН/IBAN — фіктивного формату, що не проходить реальну перевірку; позначка про це — в README.
- Адреси — вигадані («вул. Демо-Тестова, 1»). Суми й дати — детерміновано від `seed` (відносно фіксованої дати відліку в README, не `now()`).

## Seed і відтворюваність
Генератор — скрипт у `package/demo/data/` (мова — за C-00/CONFIG.md; без залежностей, яких немає в репо). `seed` записаний у README; той самий
seed → побайтово ті самі файли (перевірка: двічі згенерувати, `diff`).

## Порядок наповнення
Одиниці виміру → номенклатура/категорії → контрагенти → склади/локації → прайси → відкриті документи → історія → ролі/користувачі останніми.
Демо-дані будуються **поверх** шаблонів A-13 (не замінюють їх); порядок імпорту A-13 береться з `package/master-data/README.md`.
Охоплення: кожен процес і кожна роль з plan.md мають хоча б один запис, на якому процес проходить від початку до кінця.

## Grep-перевірки (`synthetic-data`)
```
grep -rEn '[A-Za-z0-9._%+-]+@' data/ | grep -v '@example.com'          # має бути порожньо
# телефони — лише колонки phone/mobile (за заголовком CSV), не суми/дати/IBAN:
awk -F, 'NR==1{for(i=1;i<=NF;i++)if($i~/phone|mobile/)c[i]=1;next}{for(i in c)print FILENAME":"NR":"$i}' data/*.csv | grep -Ev '<резервний_діапазон>'   # має бути порожньо
grep -rFif <(реальні_назви_з_ТР) data/                                    # збігів немає (список — з ТР, у репо не зберігається)
```
Знайшлося — виправити генератор, перегенерувати, повторити (це власна помилка, лічиться в `maxAttempts`).
