# Заборонені формулювання (DT-honesty)

Перевірка — `grep -iE` по `landing.md`, `emails.md`, чернетках Gmail. Збіг = FAIL. Список можна розширювати (через PR).

| Шаблон (укр./рос.) | Чому | Дозволена заміна |
|---|---|---|
| готовий продукт, готове рішення, готовий до використання / готовый продукт | продукту ще немає | «прототип» |
| вже працює, працює з коробки, встановіть і користуйтесь / уже работает | прототип не в роботі | «показуємо на прототипі» |
| гарантуємо, гарантія результату / гарантируем | обіцянка без підстав | прибрати |
| впровадимо за N днів/тижнів/місяців, запуск за / внедрим за | терміни не оцінені | «пілот з <місяць>» |
| економія N%, окупність, ROI, зменшимо витрати на | немає даних | прибрати або назвати біль без цифр |
| ціна, вартість, від N грн/$/€, знижка, тариф / цена, стоимость | ціни не називаються | «умови пілоту — за договором» |
| конкуренти гірші, єдине рішення, №1 | непідтверджено | прибрати |
| обмежена пропозиція, лише сьогодні | тиск | прибрати |

Обов'язкові фрази: «Прототип» (лендинг, листи) і «пілот з <місяць>». Функції з позначкою «код/складно» у
`complexity.md` — лише «у плані пілоту». Передоплата — лише «за пілот за договором».
