# Шаблон `prototype-real/README.md` (A-21, крок 9)

**Маркери фактів (обов'язково; `A-21.yaml` запускає `check_facts.py facts.json PLAN.md README.md`, потім з `--require-markers`).** Кожне число з одиницею (%, год, грн, шт.), що походить зі зрізу (значення з DOM), у README і `PLAN.md` ставиться з маркером `<!--fact:facts.<сцена>.<ім'я>-->` одразу після числа (угода — `flow-autocheck/references/checks.md`, «Маркери фактів»). Ключ — стабільний: `facts.<сцена>.<ім'я>` зі словника `facts{}` у `facts.json` (його пише `rec_lib.fact()`; символи поза літерами/цифрами/`_-` замінені на `_`); позиційні `checks.<n>.expected` не використовувати (зсуваються при перезйомці). Числа-припущення (діапазон калібрування «маржа 12–40 %», обсяги демо-даних) зі зрізу не походять: подавати словами без одиниць у тексті поруч із числом або виносити в таблицю «Припущення даних» з маркером на фактично виміряне значення; якщо діапазон лишається з одиницею — додати його як факт (сцена `calibration`) і позначити. Число з одиницею без маркера = FAIL автоперевірки.
