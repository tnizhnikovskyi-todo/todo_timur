# Шаблон `prototype/README.md`

1. **Як відкрити.** `index.html` — один файл, без мережі; відкривається з `file://` і з архіву PR. Стартовий маршрут,
   перемикач ролей, банер «Прототип, не робоча система».
2. **Покриття.** Таблиця S-xx → маршрут → тип (+ додані екрани з позначкою «додано для SC-xx, немає в screens.md»);
   таблиця SC-xx → spec → відео → PASS.
3. **Трасування.** `SC-xx.n → S-xx → F-xx → ROLE-xx` для кожного кроку; `n` — номер рядка в таблиці кроків сценарію в `scenarios.md`.
4. **Припущення даних.** Величина → діапазон → джерело `repo:<шлях>@<sha>§<заголовок>` або «припущення»; `seed`; дата відліку.
5. **Імітація.** Перелік `calc` (id, що імітується) — посилання на колонку в `complexity.md`.
6. **Відхилення від A-20.** Додані екрани й причини; розриви, повернуті на A-20 (якщо були).
7. **Версія.** sha256 `index.html`, SHA входів `concept/`, версії `prototype-builder` і `build-allocator`.
8. **Обмеження.** Що в прототипі не працює (логіка, інтеграції, права) — одним списком.
