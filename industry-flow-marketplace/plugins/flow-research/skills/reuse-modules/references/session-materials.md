# Матеріал для сесії з власником (режим `session`)

Файл `research/reuse-session.md` (лише чернетка питань; сама сесія — `human_substep`).
1. Одна таблиця кандидатів: модуль · що закриває (F-xx, простою мовою) · версія · права · попередня рекомендація AI (беремо / адаптуємо / ні) з причиною.
2. Питання ≤10, кожне з рекомендацією й замовчуванням: «беремо / адаптуємо / ні» по кожному кандидату; «чий це код і чи можна використати»; «чи ставити в ядро CE, чи в окремий модуль td_*_ee».
3. Питання, що вже закриває анкета (редакції, ліцензія як замовчування), не ставляться (`INT-dup`).
4. Рекомендація, що суперечить анкеті (`licenses`, `editions`), — лише як «альтернатива» з причиною.
5. Після сесії власник відповідає повідомленням; AI-наряд `decide` бере посилання з `resume`.
