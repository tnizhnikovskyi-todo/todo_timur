# Набір стилів Odoo 19 для прототипу (A-21)

Ресурс для `prototype-builder`: прототип імітує вигляд Odoo 19 (спільна оболонка), без залежностей від мережі (лише `file://`). Значення — орієнтири, не копія коду Odoo; наявність справжніх токенів перевіряти `boost:source-check` по `odoo/addons/web`.

- Каркас: верхня панель (ліворуч меню застосунків, по центру навігація, праворуч користувач), під нею панель керування (хлібні крихти, кнопки дій, перемикач виглядів), нижче область подання.
- Подання: list (таблиця з чекбоксами, підсумки), form (sheet, статусбар, notebook, chatter праворуч або знизу), kanban (колонки за стадією, картки), dashboard (плитки з лічильниками), wizard (модальне вікно з кнопками «Підтвердити / Скасувати»).
- Кольори: основний фіолетово-синій акцент Odoo (`#714B67` у community-стилі), текст `#212529`, фон `#f9fafb`, межі `#dee2e6`; успіх/попередження/помилка — зелений/жовтий/червоний badge.
- Шрифт: системний sans-serif, 14px; розмір заголовків форми 20–24px.
- Обов'язково: банер «Прототип — не продукт» на кожному екрані; `data-testid` на кнопках і полях (для записування сценаріїв); `window.__caption(text)` для субтитрів відео; hash-роутер `#/<екран>`.
- Заборонено: реальні дані клієнтів, зовнішні шрифти/CDN, зовнішні запити.
