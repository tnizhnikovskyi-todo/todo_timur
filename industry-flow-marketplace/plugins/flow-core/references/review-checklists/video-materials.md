# Чек-лист рецензента: Продаючі матеріали і відео

Крок: A-21c. Підключається ключем наряду `review.checklists: [video-materials.md]`; агент `flow-reviewer` завантажує його перед рецензією.

**Контракт знімків.** Рецензент має лише Read/Grep/Glob і браузер не запускає. Тому runner ДО рецензії готує: кадри відео на 0, 1, 3 с і далі кожні 2 с (prototype-real/video/frames/), екрани screens/ — і передає шляхи в брифі рецензії; рецензент відкриває їх через Read. Знімків чи кадрів немає або шляхів у брифі немає — **major** «runner не підготував матеріали для перегляду», решту пунктів не позначай «так».

**Спершу відкрий результат** — прототипні відео 16:9 і 9:16, SHOW.*, captions.yaml — відкрий підготовлені кадри через Read (текстові файли — SHOW, captions — також). Висновок за самим текстом звіту без відкриття результату недійсний.
Серйозність: кожен пункт із відповіддю «ні» = **major**; minor, що впливає на рішення власника (обсяг, відкинуте, редакції), піднімається до **major**.
Вихід — список зауважень `{серйозність, місце, що не так, що зробити}` (формат — `agents/flow-reviewer.md`); пункт без перевірки очима не позначай «так».

## Пункти
1. [ ] Формати відповідають анкеті `materials.formats` (16:9, 9:16 для reels, мобільний, one-pager).
2. [ ] Жодного статичного кадру довше 2 с (`check_video.py`, VID-freeze); динаміка схваленої версії збережена (затверджене не міняється без рішення власника, порівняння «було / стало»).
3. [ ] Гачок у перші 0–3 с: проблема або обіцянка, а не заставка.
4. [ ] Титр ≥1,5 с, не закриває доказ у кадрі; обіцянка титра видна в кадрі.
5. [ ] Телефон у кадрі займає ≥85 % ширини вертикального відео.
6. [ ] Блок для керівника (~10 с) присутній.
7. [ ] Бренд ToDo лише в заставках і титрах, не поверх інтерфейсу; логотип, кольори, шрифт за `BRAND.md`.
8. [ ] Числа в титрах і SHOW збігаються з `facts.json`; приватних даних немає.
9. [ ] Матеріали продають рішення, а не показують екрани: кожна сцена відповідає на заперечення з `SALES §2`.

## Вердикт
Зауваження major — повернення виконавцю (до `review.max_rounds` + 1 контрольний круг). Лише minor, що не впливають на рішення власника, — прийняти з переліком.
