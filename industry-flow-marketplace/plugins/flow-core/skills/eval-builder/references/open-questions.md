# Відкриті питання eval-builder

Нотатки проєктування для власників; агент їх не виконує й не вгадує.

Закрито рішенням менеджера: крок виконується лише під runner'ом (ручного шляху немає); `checks/C-04.yaml`, `C-07.yaml` додано; команди CLI виконує runner за рядком «КОМАНДИ:»;
`params.mode` для C-04/C-07 внесено в `naryad-format.md`. Лишається:
1. Картки C-04/C-07: `skillRef` -> `flow-core:eval-builder@<версія>` першим (C-07: `debug-root-cause` — вхід); `done` C-07: «пропозицію пониження сформовано, кейс інциденту є»; оновити CONCEPT (розклад).
2. `report-format.md`: блок `evals:`. До того носій пропозицій зрілості — `evals/INDEX.md` (таблиця 2).
