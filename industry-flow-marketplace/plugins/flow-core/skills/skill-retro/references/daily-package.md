# Щоденний пакет Власнику продукту (`flow/lessons/PACKAGE-<YYYY-MM-DD>.md`)

Власник продукту затверджує пакет сам (рішення людини); AI-інженер — виконавець і контроль повноти. Одна кнопка «Затвердити пакет» у задачі C-08R; окремий урок — «Повернути / Відкласти» з коментарем. AI скіли без кнопки не змінює.

## Структура
1. Шапка: дата, вікно, режим, кількість сигналів/уроків.
2. **Повнота**: таблиця `сигнал → урок | не помилка (причина)`; результат `check_retro.py` (RET-*); прострочені >3 роб. днів.
3. **Уроки дня** (порядок: частота × серйозність × вартість): `LSN · крок · скіл@версія · серйозність · клас · суть (2 рядки) · докази · repeat_of · fix_ref (що змінюємо) · eval_ref (червоний на поточній)`.
4. **Процесні уроки** — окремий розділ, рішення за Власником продукту (схема, ролі, картки).
5. **Скіли з найбільшою кількістю повернень і раундів** (метрики keeper: % повернень на скіл@версію, середні `review_rounds`, `human_rounds`).
6. П'ятниця: тижневий підсумок — нові / закриті / повторні уроки, тренд.

## Після «Затвердити»
Цикл виправлення (виконавець) → рецензія → евал зелений, регрес сусідніх скілів зелений → бамп `version` (крок F/власник плагіна) → публікація в каталог → наряди нових кроків беруть нову версію. Дані клієнтів у пакет не потрапляють.
