# Шаблон опису PR (пам'ятка перевіряльнику)

Основне джерело — `package/templates/pr-checklist.md` пакета (за SHA `origin/<base_branch>`); цей файл — запасний шаблон, коли його немає (у пам'ятці вказати: «шаблон пакета відсутній»).
Той самий текст — поле `memo` звіту (`flow-core/references/report-format.md`). Лише ідентифікатори; без ПІБ, контактів і сирих даних клієнта.

```
Невпевнений: <де і чому AI не впевнений; якщо ні в чому — «не виявлено, але перевір …»>

## Що змінилось
<файли з where, одним рядком на файл>

## Де ризик
<клас ризику за кроком 13 SKILL.md або «немає»>

## Що перевірити
<пункти з check.how + зауваження AI-рецензента (важливо/дрібниця)>

Задача Odoo: <#id>  ·  Крок: <step> <scope>  ·  спроба <attempt>
Версії скілів: <плагін:скіл@версія, …>
SHA входів: <name@sha, …>
```
