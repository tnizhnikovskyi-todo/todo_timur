# Прапорці клієнта: подія → дія

Прапорці ставить і знімає скіл автоматично, завжди з «підтверджено PM» = ні + активність PM (дедлайн 1 робочий день).
Значення — лише в проєкті клієнта.

| Подія (джерело) | Прапорець / поле | Дата | Хто підтверджує |
|---|---|---|---|
| Гейт go-live (B-08d) затверджено кнопкою | «hypercare» = так | з | PM |
| B-09 стадія `Готово` | «hypercare» закрито; «на супроводі» = так | до / з | PM |
| Рішення про закінчення строку або розірвання договору супроводу (кнопка PM) | «на супроводі» закрито | до | PM |
| Запис у стоп-листі «AI зупинено» (ставить людина) | лише відображення в `flow/ai-stop.md` | з | — (скіл не змінює) |
| Рішення шлюзу «Потрібні сесії з еталонними клієнтами?» | рядок журналу з критерієм і роллю | дата кнопки | роль за `raciA` |

- Подія без рядка в таблиці → нічого не ставити, активність Тімліду «правила для події немає».
- Відкрите питання: подія завершення супроводу (q09) — поки лише рішення PM кнопкою.
- Відкрите питання: чи беруть D-01/B-10 непідтверджені прапорці — пропозиція: так, з позначкою «не підтверджено PM».
- Непідтверджені понад 1 робочий день → у звіт `reconcile`.
