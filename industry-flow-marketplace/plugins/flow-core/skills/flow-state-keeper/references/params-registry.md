# «Параметри флоу»

Рядок: `ключ, значення, роль і дата затвердження, крок-споживач, дата перегляду`. Значення — з поля гейта, не з коментаря.

## Правила
- Усі параметри операційні — повний рядок. Економічних параметрів (ціна пакета, ключі business-case) немає: 0.3.0 економіку пакета не рахує; тарифи власника — лише цитата в BOX §1.
- Параметр без ролі або дати → рядок не створювати, активність Тімліду.
- Перелік ключів береться з `preconditions` карток кроків (`reconcile`); ця таблиця — відомі на зараз:

| Ключ | Крок-споживач | Роль-власник | Тип |
|---|---|---|---|
| «A-01: критерій ранжування галузей» (формула й ваги) | A-01 | Власник продукту | операційний |
| «поріг у продукт» | D-02 | Відкрите питання: роль не визначена в плані | операційний |

Інші параметри з `preconditions` (A-05, D-02, …) — додавати за результатом `reconcile`, не вигадувати.
