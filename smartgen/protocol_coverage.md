# Покрытие протоколов SmartGen в мокапе

Источники: *HGM6100N/HGM6100CAN Communication Protocol* v1.7 (2025-07-01) и
*CMM366A/B Communication Protocol* v1.2 (2023-12-23). Контроллер HGM6120N относится к серии
HGM6100**N**, поэтому всё, что помечено «only HGM6100CAN» (ECU, DPF, SCR, DM1/DM2, расход L/h),
нам недоступно.

## Контроллер HGM6120N

### 03H — значения

| Регистры | Что | В мокапе |
|---|---|---|
| 0000–0006 | Мережа: UA/UB/UC, UAB/UBC/UCA, частота | есть |
| 0007–0013 | Генератор: напряжения, частота | есть |
| 0014–0016 | Ток A/B/C | есть |
| 0017–0022 | Температура ОЖ, давление масла, уровень топлива (%) + сопротивления датчиков | есть |
| 0023–0025 | Обороты, АКБ, D+ | есть |
| 0026–0029 | P, Q, S, cos φ | есть |
| 0030–0031 | До ТО (ч, мин) | есть |
| 0032–0033 | — | для N зарезервированы |
| 0034–0035 | Стан агрегату (16 состояний, табл. 13) + задержка, с | **частично**: показаны 4 из 16, задержка не используется |
| 0036–0037 | Стан дистанційного пуску (0/1/2: без затримки / затримка пуску / затримка зупинки) + задержка | только в «Поточні дані» |
| 0038–0039 | Стан АВР + задержка | только в «Поточні дані» |
| 0040–0041 | Стан мережі (0 норма / 1 аварія / 2 без затримки) + задержка | только в «Поточні дані» |
| 0042–0049 | Наработка, пуски, kWh (MSB×10000+LSB) | есть |
| 0050–0051 | Версия ПО / железа | есть |
| 0052–0055 | P по фазам, загрузка % | есть |
| 0056–0069 | Двигатель по ECU, **расход L/h (0066), накопленный расход L (0068–0069)** | только CAN, **недоступно** |
| 0071 | Модель контроллера | есть |
| 0072–0078 | Часы контроллера | есть |
| 0079–0081 | Дата выпуска ПО | есть |
| 0082–0091 | ECU / MTU | только CAN |
| 0092–0097 | Фазовые углы генератора и сети | есть |
| 98–112 | Учёт топлива: изменение уровня, начальный уровень, флаг «изменение >5 %», 10 последних записей, сумма | показаны, **в логике не используются** |
| 113–114 | Совместимая версия ПК | есть |
| 2500–2511 | Точные I, P, Q, S (4 байта) | есть |

Особое значение: **32766 = нет данных** (на панели «###»). В мокапе не обрабатывается.

### 01H — сигналы

Покрыты 0000–0004, 0006–0053, 0056–0061, 0064–0069, 0072–0078.
Не показаны сигналы, которые есть именно в серии N:

| Адрес | Сигнал |
|---|---|
| 0054 | Аварийная остановка: протечка жидкости |
| 0062 | Аварийная остановка по входу «перегрузка по току» |
| 0063 | Аварийная остановка по входу «превышение оборотов» |
| 0070 | Аварийная остановка: высокая температура (аналоговый датчик) |
| 0071 | Аварийная остановка: низкое давление масла (аналоговый датчик) |
| 0079 | Предупреждение: протечка жидкости |

0080–0127 — только CAN.

### 05H — команды (HGM6120)

| Адрес | Команда | В мокапе |
|---|---|---|
| 0000 | Пуск | есть |
| 0001 | Стоп | есть |
| 0002 | **Тест** | **нет** |
| 0003 | Авто | есть |
| 0004 | Ручний | есть |
| 0005 | Автомат генератора: замкнути/розімкнути (**переключатель**) | есть, как две отдельные кнопки |
| 0006 | Автомат мережі: замкнути/розімкнути (**переключатель**) | есть, как две отдельные кнопки |

Команда отправляется один раз. Для автоматов это переключатель, поэтому перед отправкой нужно
прочитать текущее положение (01H 0006/0007), иначе можно разомкнуть вместо «замкнуть».
Дистанционное управление блокируется сигналом «Дистанційне блокування» (01H 0004) и входом
модуля «Заборона дистанційного керування»: пульт при этом должен быть недоступен.

## Модуль CMM366B-4G

Сам по себе данных о генераторе не добавляет: он опрашивает контроллер теми Modbus-командами,
которые сервер вернул при регистрации (`para_command`), и пересылает ответы (`reqdata` —
полный набор, `reqdatachange` — только изменения). Своё у модуля:

| Поле | Где | В мокапе |
|---|---|---|
| hostid, hostname | регистрация | только ID |
| longitude, latitude, altitude, gpsen (0 Baidu / 1 GPS) | регистрация | есть |
| moduletype (модель контроллера) | регистрация | нет |
| modulePort (LINK / RS485 / RS232 / USB), moduleBaud | регистрация, writeConfig | есть |
| online_rate / offline_rate | задаёт сервер | **выдуманы** («3 с / хв») — должны браться из настройки |
| data_mode (полный / только изменения) | задаёт сервер | нет |
| HB (heartbeat) | периодически | «Зв'язок: онлайн, N с тому» |
| AccessAlarm, FireAlarm, AlarmInput, InhbitRemote | reqdatachange | показаны в карточке, **не попадают в тривоги/події и не блокируют пульт** |
| timing (синхронизация времени), reset, writeConfig | сервер → модуль | нет (служебные) |

История на стороне контроллера по Modbus не отдаётся (журнал событий панели недоступен),
поэтому вся история в «Показання» и «Події» строится нами из опросов — так мокап и устроен.

## Что добавить в мокап

1. Все 16 состояний агрегата (Преднагрев, Подача топлива, Прокрутка, Пауза между попытками,
   Безопасный пуск, Холостой ход, Прогрев, Ожидание нагрузки, Работа, Охлаждение, Холостой
   перед остановкой, ETS, Ожидание остановки, **Невдала зупинка**, После остановки) — в
   statusbar сгруппировать в 4–5 этапов, точное состояние и обратный отсчёт задержки
   (0035/0037/0039/0041) показывать на пульте.
2. Команда «Тест» и режим «Тест» в поле «Режим».
3. Блокировка пульта при 01H 0004 или входе модуля «Заборона дистанційного керування».
4. Шесть недостающих сигналов серии N (0054, 0062, 0063, 0070, 0071, 0079).
5. «Немає даних» вместо значения при 32766.
6. Входы модуля (пожар, доступ в помещение, тревожный вход) — в «Тривоги» и «Події».
7. Учёт топлива контроллером (98–112, флаг «изменение >5 %») — как триггер подтверждения
   заправки и событие **«падіння рівня без роботи»** (возможный слив).
8. Карточка модуля: имя, модель контроллера из регистрации, режим передачи и частота
   из настройки, а не выдуманные.
