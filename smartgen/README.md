# SmartGen: мокап Odoo-модуля генератора

Мокап формы генератора (контролер HGM6120N, модуль связи CMM366B-4G) в стиле Odoo 20.
Страницы: «Генератор» (форма с пультом), «Показання», «Аналітика», «Події», «Заправка».

«Заправка»: запас палива в каністрах (каждая каністра — запись: объём, сколько в ней, где хранится),
рух запасу (надходження, заправки генератора, коригування, списання), витрата в літрах
(L/год, L/kWh, L на добу, стоимость) и журнал заправок со сверкой по датчику уровня.
Контроллер отдаёт уровень в процентах; в литры переводим по объёму бака **145 L** (`TANK` в коде).
Везде в аналитике, событиях и показаниях топливо в литрах; проценты остались только в сыром регистре 03H/0021.

- Исходник: `mockup_odoo_genset.html`
- Артефакт: https://claude.ai/artifact/CwaaS3x2U3FHWdKwtFGH5Q («Генератор · Садова вулиця»), сейчас v8

## Требования к дизайну

- Стиль Odoo 20: navbar, control panel, statusbar, sheet, notebook, chatter. Цвета из `web.assets_web`.
- Одна тема для всей страницы: пульт в тех же цветах, что и форма. Тёмные значения токенов
  включаются только по системной настройке.
- Один шрифт: системный стек Odoo. Material Symbols только для иконок.
- Мобильная вёрстка обязательна: на 390 px нет горизонтального скролла страницы,
  вбок прокручиваются только таблицы, вкладки и меню.

## Проверка

```sh
node smartgen/tools/check_layout.js                     # светлая тема
node smartgen/tools/check_layout.js "" "" light,dark    # обе темы
```

Скрипт снимает все страницы на 1440 и 390 px в `smartgen/shots/` (каталог в `.gitignore`),
сообщает о горизонтальном переполнении и ошибках JS. Код выхода 1, если что-то найдено.

## Публикация

Публикуется сам `mockup_odoo_genset.html` в тот же URL артефакта. Обёртку (doctype, viewport)
сервис добавляет сам; `tools/publish_head.html` — её копия, только для локальной проверки.
