# Склад WH — отдельный артефакт со складом в интерфейсе Odoo

Артефакт: https://claude.ai/artifact/9uobU9NBT4bwLssUkA2Bsj (приватный, «Склад меблевої фабрики»)
Исходник страницы — сам артефакт: его можно прочитать через Artifact `read` по ссылке выше и опубликовать обратно по тому же URL.

## Данные

- Всё, что нужно, уже встроено в страницу: JSON `odoo-data` — выгрузка Odoo 19.0 · timur-o19demo.todo.ltd, база `odoo`, демо-время 2026-10-12 10:30:
  - `products` — 57 товаров;
  - `locations` — 689 мест хранения, 805 остатков (stock.quant), правила пополнения (144 ячейки фурнитуры, 19 ниже минимума);
  - `purchase_orders` (3), `productions` (32, урезанные), `quality_checks`.
- Других источников у страницы нет, читать для доработки ничего, кроме самого артефакта, не нужно.
- Данные Odoo — снимок, в реальном времени не обновляются; Odoo страница не меняет.

## Этапы

1. **Отдельная страница склада** без 3D: KPI, список товаров с поиском и категориями, карта мест по зонам, карточки товара и места.
2. **План 2D/3D** (нарисован с нуля): условная раскладка склада, три.js r147 с jsDelivr, подсветка товара, фильтр «нижче мінімуму».
3. **Интерфейс как Odoo 17–19**: панель приложения «Склад», контрольная панель (хлебные крошки, поиск с фасетами, «Фільтри / Групувати за», переключатель видов, пейджер), виды список/канбан, карточки записей (smart-кнопки, группы полей, вкладки, листание ‹ ›), обзор-канбан.
4. **Внешний вид по скриншотам Odoo 19**: иконка-шестиугольник, меню с рамкой у активного пункта, бирюзовые заголовки карточек обзора, ссылки «назва — число».
5. **Меню как в Odoo 19** с выпадающими разделами. Рабочие пункты:
   - Загальний огляд → обзор;
   - Операції → Коригування залишків (остатки), Поповнення (места ниже минимума);
   - Товари → Товари;
   - Звітність → Запаси (товары списком), Розташування (список мест);
   - Налаштування → Розташування (список мест);
   - **3D** (отдельный пункт) → модель склада, стартовая страница.
   - **Інструкція** (отдельный пункт) → инструкция пользователя по 3D-модели: просмотр, выделение, редактирование, перемещение и поворот, несколько объектов, копирование, сохранение и отмена, горячие клавиши (`renderHelp`, раздел меню `help`).

   Остальные пункты Odoo (Надходження, Доставки, Партії, Упаковки, Маршрути и т. д.) показаны серыми, страниц у них нет — пока не используются.
6. **Новая модель склада (пункт «3D»)**:
   - только объекты с локацией; цех, фуры, кран, стены, колонны убраны;
   - раскладка по дереву локаций Odoo горизонтально: Вхід → Приймання → Контроль якості → Сировина → Передвиробництво → Пост-виробництво → Готова продукція → Відвантаження;
   - к уровням `complete_name` добавлены уровни из кода места: `FUR-R2-S01-L4` → Ряд R2 › Стелаж S01 › Ярус L4 (так же для `EB-U*-S*-L*`, `FG-R*-B*-L*`, `RCK-R*-<секція><ярус A–D>`, `PLT-<ряд><стос A–C>`);
   - любой уровень можно выбрать (выпадающие списки над моделью, подписи в модели, «↑», «Показати лише цей рівень» в правой панели) — остальное скрывается, камера приближается; работает в 2D и 3D;
   - подложка (пол) в 3D повторяет размер выбранного уровня с небольшим отступом (для яруса — размер его секции).

7. **Режим редактирования модели** (кнопка «✎ Редагувати» над моделью; пока только 3D-модель, Odoo не меняется):
   - клик в модели выбирает узел для редактирования (ярус, стелаж, ряд, зону);
   - в зоне: «+ Ряд» (тип мест, число стеллажей и ярусов), «+ Місце на підлозі» (тип и количество), «+ Зона»;
   - в ряду: смена типа ряда, «+ Стелаж» (или «+ Стос» для стосов плит); в стеллаже: «+ Ярус нагорі»;
   - «Прибрати» для любого узла (вместе со всем, что внутри), «↶», «Скинути до даних Odoo»;
   - новые места синие полупрозрачные («нове · лише в моделі»), коды генерируются по образцу (`FUR-R7-S01-L1`);
   - **типы мест хранения** (кнопка «Типи місць»): код, название, конструкция (полична секція / стелаж для рулонів / палетний стелаж / стос на підлозі / місце на підлозі), ширина, глубина, высота яруса, ярусов в новом стеллаже; изменение сразу перестраивает модель, можно добавить свой тип;
   - правки хранятся отдельным слоем поверх данных Odoo: документ `model/layout` в общей базе артефакта (`types`, `add`, `del`, `set`, `pos`) — видят все, кто открывает страницу, и его можно прочитать для будущей привязки к Odoo; без базы (локальный файл) — в localStorage.
8. **Перетаскивание рядов и показ до сохранения**:
   - в режиме редактирования ряд перетаскивается мышкой в 2D и 3D (если открыт уровень, в котором он стоит); положение записывается в метрах внутри родителя (`pos`), зона расширяется под ряд; «Автоматичне положення» возвращает раскладку; при наложении на соседний ряд — предупреждение;
   - любая правка сначала только показывается в модели (бирюзовым, «не збережено»): в формах кнопки «Показати» (повторный показ той же формы заменяет предыдущий) и «Зберегти»;
   - незбережені зміни собираются по объекту, где их сделали: в панели объекта — список и «Зберегти <объект>» / «Скасувати»; сверху — «Зберегти все», «Скасувати все», «↶» (убрать последнюю); типы мест сохраняются кнопкой «Зберегти типи» в окне типов;
   - вместе с изменением сохраняются те, без которых оно не имеет смысла (новый ряд — для нового стеллажа в нём);
   - несохранённое хранится только у этого зрителя (localStorage) и переживает перезагрузку, в общую базу уходит лишь сохранённое.
9. **Поворот, уведомления, выделение уровней**:
   - ряд поворачивается на 90° (кнопка «⟳ Повернути на 90°» в панели ряда или клавиша R в режиме редактирования): стеллажи идут вглубь, а не вдоль; хранится в `rot`; второй поворот подряд отменяет первый;
   - после «Зберегти» в правом верхнем углу появляется уведомление «Збережено: <объект> · N змін» (или ошибка), после «Скасувати» — сколько изменений отменено;
   - клик в модели (2D и 3D, в обычном режиме и в редактировании) выделяет и подсвечивает уровень, ничего не скрывая; переключатель «Клік виділяє: Місце / Стелаж / Ряд / Зона» задаёт, что выделять; повторный клик по выделенному — уровень выше; в панели — цепочка уровней для выделения, «Показати лише цей рівень» (скрыть остальное) и «Зняти виділення». Двойного клика для приближения нет.
10. **Дублирование**: в режиме редактирования «⧉ Дублювати» в панели (или Ctrl+D) создаёт рядом копию выделенного — яруса (новый ярус наверху), стеллажа, ряда (с поворотом; ряд, поставленный вручную, копируется рядом с ним), места на полу (KIT-01 → следующий свободный код) или целой зоны; та же конструкция и типы, места новые и пустые; копия сразу выделяется, изменение «не збережено» относится к самой копии.
11. **Горячие клавиши и выделение нескольких объектов** (режим редактирования; на Mac — ⌘ вместо Ctrl, работают и в украинской раскладке):
    - Ctrl+клик в модели (2D и 3D) добавляет объект в выделение или убирает из него; панель «Виділено N об'єктів» — список с ×, «Дублювати всі», «Копіювати», «Повернути ряди», «Прибрати всі», «Зберегти виділене»;
    - перетаскивание любого выделенного двигает всё выделенное вместе (ряды, места на полу, зоны; выделенный ярус или стеллаж тянет свой ряд) — одно изменение «Переміщено разом»; R поворачивает все выделенные ряды; Esc снимает выделение;
    - места на полу теперь тоже перетаскиваются, зона — если она выделена;
    - Ctrl+C копирует выделенное, Ctrl+V вставляет: в выделенный уровень, если он подходит (ярус → в стеллаж, стеллаж → в ряд той же конструкции, ряд/место/зона → в зону), иначе ближе всего по дереву, иначе рядом с оригиналом; кнопка «Вставити … → <куда>» в панели;
    - Ctrl+Z убирает последнее несохранённое изменение (с уведомлением), Ctrl+Shift+Z или Ctrl+Y возвращает; сохранённое так не отменяется.

12. **Новое приложение конструктора** `warehouse3d/app/` (пакет W-01 плана `warehouse3d/build/PLAN.md`): ядро без DOM (`src/core`), 2D/3D и панели (`src/view`), запуск (`src/host`), интерфейс uk/en, инструкция «Інструкція / Help»; `npm test`, `npm run build`, `npm run e2e` — см. `warehouse3d/app/README.md`. Прототип — `warehouse3d/prototype/`.
    - W-17: данные склада на модели — «Оновити дані» (остатки без перестройки плана), переключатель «Показник» (пять тепловых карт: заполненность, ниже минимума, пустые места, ABC, возраст запаса; цвета в 2D и 3D), поиск «где лежит», карточка места со ссылкой «Відкрити в Odoo»; модуль `wh_constructor` читает движения (`/api/read/moves`) и дату поступления остатков. В демо движения и возраст синтетические (помечены «демо»). Подробно — `warehouse3d/app/README.md`.
    - W-18: совместная работа — варианты планировки («Як є», «Проєкт A»…: создать из текущего, переключить, сравнить цифры), история версий («Історія»: просмотр, «Відновити», комментарий при «Зберегти»), комментарии и задачи «перевірити на місці» на объектах (значки в 2D и 3D, список с фильтром и переходом), роли по группам Odoo, блокировка зоны со значком «кто правит» (подробнее — `app/README.md`, «Совместная работа»).

## Устройство страницы (для доработки)

- Один HTML-файл, данные встроены в `<script type="application/json" id="odoo-data">`.
- `ACTIONS` — действия (виды, поиск, фильтры, группировки); `MENU` / `MENU_ITEMS` — верхнее меню; `COLS` — колонки списков; `renderForm` — карточки product / location / po.
- Модель: `codeSegs` (разбор кода места), `buildTree()` (дерево локаций Odoo + слой правок `EDIT`), `BASE_TYPES` / `TY()` (типы мест), `measure` / `place` (раскладка в метрах), `rebuildModel()` после каждой правки, `Plan` (2D-SVG и 3D-сцена, `planState.focus` — выбранный уровень, `planState.esel` — выделенный узел в обычном режиме и в редакторе, `planState.pick` — что выделяет клик, `resolvePick` / `selectNode`).
- Редактор: `SAVED` (сохранённое) + `PENDING` (несохранённые изменения `{obj, label, diff}`) → `EDIT` (что показываем, `recompute`); `diffEdit` / `applyDiff`; `change` (показ изменения), `saveObj` / `discardObj` / `undoEdit`; `OPS` (добавление, удаление, тип ряда; `move`, `rotate`, `dup`, `del` принимают и список узлов; `dup(ids, target)` — вставка через `dropInto`/`canHold`); `planState.msel` / `selIds()` — несколько выделенных, `dragSet` — что тянуть; `CLIP` / `copySel` / `pasteSel`; `undoEdit` / `redoEdit` (`REDO`); изменение может принадлежать нескольким узлам (`objs`); `notify` — уведомления; `renderEditSide`, `openTypes`, `Store` (сохранение `SAVED` в базу артефакта `model/layout` или localStorage); перетаскивание — `posOverride` в `measure`, обработчики в 2D (`S2`) и 3D (`makeThree`).
- three.js грузится лениво при первом переходе в 3D: `three@0.147.0/build/three.min.js` и `examples/js/controls/OrbitControls.js` с cdn.jsdelivr.net.
