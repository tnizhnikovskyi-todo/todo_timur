# TYPES — каталог типов мест хранения конструктора склада

Справочник для конструктора (Odoo 18/19). Запрос заказчика: «все возможные типы локаций».
Состав: 50 типов в 5 группах, 9 параметрических 3D-форм. Источник — складская практика и модель `stock.location`.

Обозначения.
- **Ф1–Ф5** — формы, уже есть в прототипе: Ф1 полична секція, Ф2 стелаж для рулонів, Ф3 палетний стелаж, Ф4 стос на підлозі, Ф5 місце на підлозі.
- **Ф6–Ф10** — новые формы (см. §3).
- **Уровень Odoo** — на каком уровне дерева лежит `internal`-локация с остатками (лист). Уровни: З зона, Р ряд/стеллаж, С секция, Я ярус, П позиция. Всё выше листа — `view`.
- **Фабрика** — встречается на мебельной фабрике: ● обычно, ○ редко/по условию, — нет.
- Размеры в метрах, нагрузка в кг, если не указано иное.

## 1. Типы локаций Odoo (`stock.location.usage`)

| usage | Что это | Рисовать | Комментарий |
|---|---|---|---|
| `view` | Контейнер для группировки; остатков не держит | да, как рамка/группа | Склад, зона, ряд, стеллаж, секция. Родитель для `internal` |
| `internal` | Физическое место с остатками | **да, основной объект** | Лист дерева: ярус или позиция, зона на полу, буфер |
| `supplier` | Виртуальная: источник поступления | нет | Только значок/подпись у ворот приёмки |
| `customer` | Виртуальная: получатель отгрузки | нет | Значок у ворот отгрузки |
| `inventory` | Виртуальная: потери, корректировки, `Scrap` | нет | Для типов «брак» хранить ссылку на неё, не рисовать |
| `production` | Виртуальная: производство (расход сырья, выпуск) | нет | Связь с буфером WIP (Б8) — физически он `internal` |
| `transit` | Виртуальная: в пути между складами/компаниями | нет | Опционально: стрелка между складами |

Служебные поля `stock.location`, которые заполняет конструктор: `name`, `location_id` (родитель), `usage`, `barcode`,
`storage_category_id`, `posx/posy/posz` (координаты для сортировки обхода), `removal_strategy_id`, `scrap_location`,
`replenish_location`, `cyclic_inventory_frequency`. Вместимость — через `stock.storage.category`
(`max_weight`, правила по продукту и по `stock.package.type`).

Стандартные точки многошаговых маршрутов (`WH/Input`, `WH/Quality Control`, `WH/Packing Zone`, `WH/Output`) — это
`internal`-зоны, они соответствуют типам группы Б.

## 2. Физические типы мест хранения

### Общие параметры (задаёт конструктор для любого стеллажного типа)

| Параметр | Диапазон | Примечание |
|---|---|---|
| Ширина секции (по фронту) | 0.6–3.9 | Паллетный: 1.8 / 2.7 / 3.6; полочный: 0.9–1.2 |
| Глубина | 0.3–1.4 | Паллет 0.8×1.2: глубина 0.9–1.1 при фронте по 1.2 |
| Высота яруса (свет) | 0.3–2.5 | Паллет с грузом 1.2–1.8 |
| Число ярусов | 1–12 | Включая нулевой (пол). До 30–45 м у автоматических |
| Позиций на ярусе | 1–4 | Паллет: 2–3 на балке 2.7–3.6 |
| Нагрузка на ярус / на позицию | 50–3000 / 20–1500 | `max_weight` категории хранения |
| Секций в ряду, рядов | 1–60, 1–40 | Нумерация кода места: ряд-секция-ярус-позиция |
| Проход (между рядами) | 0.8–4.5 | Зависит от техники: ручная 0.8–1.2, ричтрак 2.7–3.5, VNA 1.6–1.9 |
