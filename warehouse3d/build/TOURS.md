# Туры по типовым задачам (пакет W-24)

Запуск: меню «Тури» (в верхней панели / «Ще», на телефоне — в меню), список в «Інструкція / Help», ссылка `#tour-<id>`.
Туры, меняющие данные, идут в учебной копии (временный вариант W-18); в конце — «Залишити зміни» или «Скасувати зміни туру».

| ID | Тур | Для кого | Шаги (кратко) | Меняет данные | Нужен Odoo |
|---|---|---|---|---|---|
| T-basic | Перший огляд | все | план 2D/3D, рівні, виділення, «Редагувати», каталог, перевірки, план змін, інструкція (текущий тур W-20) | нет | нет |
| T-import | Склад з Odoo: завантажити й розкласти | аналитик | «Проєкт з Odoo…» (вне Odoo — «Імпорт локацій» из файла-примера), розбір кодів, лоток «Не розміщено», авторозкладка | да | нет (файл) |
| T-scratch | Новий склад з нуля | аналитик | мастер: будівля → зони → ряди → адресація → перевірки → план змін | да | нет |
| T-rack | Додати ряд стелажів | аналитик, керівник | выбрать зону → «Редагувати» → каталог/масове створення → «Показати» → перетягнути/повернути → «Зберегти» | да | нет |
| T-address | Перенумерувати зону | аналитик | шаблон коду зони, напрямки, попередній перегляд, перенумерація, конфлікти, Ctrl+Z | да | нет |
| T-putaway | Налаштувати розміщення | аналитик | категорія зберігання → призначити зоні → правило розміщення → «Куди покладе Odoo» → min/max у картці місця | да | частично (оценка вне Odoo) |
| T-apply | Перевірити й застосувати в Odoo | аналитик | панель проблем → «План змін» → вибір частини → застосувати / файл → журнал і відкат | да | для применения (вне Odoo — файл) |
| T-find | Знайти товар і місце | кладовщик, керівник | пошук «де лежить», перехід за кодом / сканером, теплові карти, картка місця (есть вариант для телефона) | нет | нет |
| T-labels | Надрукувати етикетки | кладовщик, аналитик | виділити ряд → «Етикетки» → попередній перегляд → PDF / ZPL | нет | нет |
| T-docs | Документи для закупівлі | керівник | специфікація стелажів, план у PDF, місця в Excel | нет | нет |
| T-team | Спільна робота | керівник, аналитик | варіант планування і порівняння, коментар «перевірити на місці», історія і відновлення | да | частично |
