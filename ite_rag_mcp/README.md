# ite-rag — MCP-сервер поиска по базе знаний ITnet2

Даёт Claude (и любому MCP-клиенту) поиск по RAG-базе ITnet2 в Qdrant:
справка, формы и таблицы, инструкции по учёту, обзоры библиотек, журнал
находок `CLAUDE.md` и серверный код.

## Что в базе

| Коллекция | Фрагментов | Содержимое |
|---|---|---|
| `ite_docs` | 15 588 | `help` — справка из 181 CHM; `forms` — 1 845 форм и таблиц с полями; `instr` — 64 пошаговые инструкции по бухучёту; `libs` — обзоры 91 библиотеки; `claude` — 47 разделов журнала `CLAUDE.md` |
| `ite_code` | 18 268 | методы (11 556) и классы (6 712) `ITnet2.*`: сигнатура, namespace, файл, таблицы БД |

## Инструменты

| Инструмент | Что делает |
|---|---|
| `ite_search` | гибридный поиск (смысл + BM25, слияние RRF). Фильтры: `collection` (`docs`/`code`/`all`), `source`, `kind`, `library`, `table`; `mode` = `hybrid`/`dense`/`bm25` |
| `ite_get_document` | все фрагменты документа по `doc_id` из результатов поиска, склеенные по порядку |
| `ite_overview` | число фрагментов и распределение по полю — чтобы узнать значения фильтров |

Для точных имён (класс, метод, код таблицы `DMZ`) лучше `mode=bm25`, для
вопросов своими словами — `hybrid`.

## Векторы — важно

Индекс построен **fastembed 0.7.x** моделью
`sentence-transformers/paraphrase-multilingual-mpnet-base-v2` (768, COSINE,
mean pooling) по полю `text`; разреженные — `Qdrant/bm25` с модификатором IDF.
fastembed 0.5.x даёт другие векторы, поэтому версия в `requirements.txt`
закреплена на `>=0.7,<0.8`. Совпадение проверено: пересчитанные векторы
существующих точек дают косинус 1.00000 с сохранёнными.

Первый запуск скачивает модель (~1 ГБ) в кэш fastembed; сервер начинает её
загружать сразу при старте, в фоне.

## Установка

```bash
cd ite_rag_mcp
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
```

Подключение в Claude Code (ключ берётся из окружения, в репозиторий не кладётся):

```bash
claude mcp add ite-rag -e QDRANT_API_KEY="$QDRANT_API_KEY" -- \
  "$PWD/.venv/bin/python" "$PWD/server.py"
```

Или вручную в `.mcp.json` / настройках клиента:

```json
{
  "mcpServers": {
    "ite-rag": {
      "command": "/путь/к/ite_rag_mcp/.venv/bin/python",
      "args": ["/путь/к/ite_rag_mcp/server.py"],
      "env": { "QDRANT_API_KEY": "${QDRANT_API_KEY}" }
    }
  }
}
```

## Переменные окружения

| Переменная | По умолчанию | |
|---|---|---|
| `QDRANT_API_KEY` | — | обязательна |
| `QDRANT_URL` | `http://167.233.49.46:6333` | порт открыт из офиса, VPN и для облачных сессий Claude |
| `ITE_BM25_LANGUAGE` | `english` | язык стеммера `Qdrant/bm25`; должен совпадать с тем, что был при индексации |
| `ITE_DENSE_MODEL`, `ITE_BM25_MODEL` | см. выше | менять только вместе с переиндексацией |

## Облачная сессия Claude Code

В облачном контейнере наружу ходят только через HTTPS CONNECT-прокси,
который сверяет заголовок `Host`. Поэтому туда сервер подключается через
локальный туннель:

```bash
python3 ccr_tunnel.py 16333 167.233.49.46 6333 --http &
QDRANT_URL=http://127.0.0.1:16333 .venv/bin/python server.py
```

Исходящие адреса облачных сессий меняются от соединения к соединению
(`160.79.106.0/24`), поэтому на сервере открыта подсеть, а не один IP.
Из офиса и VPN туннель не нужен.
